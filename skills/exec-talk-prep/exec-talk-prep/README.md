# exec-talk-prep · 高管致辞 / 谈参 / 主持稿 准备助手

基于花草团队《文化类事件SOP&SLA》抽取的可复用技能，专门解决文化活动里
"写给人看的高管内容"这一最难、最易踩坑、又最高频的环节。

## 能做什么
- 写**高管谈参**（Dowson / Wang / GM / 线负责人的发言要点 + QA 预案 + 禁忌）
- 写**高管致辞逐字稿**（开场 / 总结 / 颁奖，含脱稿与时长提醒）
- 写**主持稿 / 串词**（开场暖场、环节衔接、互动导入、纪律与保密提醒）
- 给**发言人稿件把关清单**（owner / SLA）
- 查**坑点**与**参考模板 / 素材资源**

## 目录
- `SKILL.md` —— 主文件（用途 / 数据来源 / 工作流 / 边界）
- `references/extracted_data.json` —— 语义化抽取数据
- `prompts/` —— info_collection / draft_talking_points / draft_speech / draft_host_script / query_detail / resource

## 数据来源
【花草团队】文化类事件SOP&SLA.xlsx → sheet1(厘清Why) / sheet2(持续完善的指引) / sheet5(互动环节沉淀)

## 边界
- 高管职位描述、谈参口径必须（需确认），不臆造
- 真实姓名 / 对接人默认脱敏
- 保密要求（不截屏录屏）必含于主持稿纪律段
- 真实高管发言定稿前需经本人 / 秘书确认
