# 主持稿 / 串词模板（draft_host_script）

> 用途：生成员工大会 / offsite 主持人串词，含开场暖场、环节衔接、互动导入、纪律与保密提醒。
> 主持人需彩排 2-3 次，至少半脱稿（原始数据）。

## 输入变量
- 场合：{{occasion}}
- 总时长：{{total_min}}
- 环节清单：{{agenda}}（例：开场→业务图景→AI畅想→轻研讨→颁奖→总结）
- 是否有互动环节：{{has_interaction}}
- 是否线上（Webinar / 多地连线）：{{online}}

## 输出结构（串词）
### 【开场暖场】（提前 30min 放暖场音乐/视频 + 签到）
各位同事上午好，我是今天的大会主持人 ____。
欢迎大家来到 ____（场合）。在正式开始之前，先同步几条纪律：
1）请各位将手机调至静音；
2）**本次会议内容不截屏、不录屏**（保密要求，必讲）；
3）线上参会的同事请修改视频设备名为所在地区，并开启等候室由工作人员放行。

### 【环节衔接】（每个环节之间热场，与控台配合）
例：「刚才 ____ 分享了 ____，接下来的环节我们换个节奏 ——」
（控台切屏 / 联席主持人共享屏幕提示）

### 【互动导入】（如有，从 references.host_script_elements.互动导入 选）
- 扫码答题（趣味版关联智能表格实时展示，效果 ⭐⭐⭐⭐⭐）
- 答案之书 / 词云图 / 数智人开场介绍 + 保密提醒
- ⚠️ 线上互动：公告栏同步发【链接】（不是二维码），手机端直接点

### 【颁奖环节】（如有）
有请 ____（GM）为 ____ 颁奖，提前准备花束&锦旗/奖杯/礼品；可播放 AE 颁奖视频。

### 【收尾】
感谢各位，会议内容将沉淀至云知/KM；散会。

## 纪律与保密段（必须包含，来自 SOP）
- 手机静音 / 不截屏录屏（原始数据）
- 线上等候室监控静音、各地改设备名（原始数据）
- rooms 会议室手动开录制（原始数据）
- 数智人可用于提醒大会信息保密（原始数据）

## 标注要求
- 引用 SOP 标（原始数据），推断标（经验推断），待补标（需确认）。
- 末尾附「需确认清单」：环节时长、控台配合、保密口径。
