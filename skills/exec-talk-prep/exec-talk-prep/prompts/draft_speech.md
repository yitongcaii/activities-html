# 高管致辞逐字稿模板（draft_speech）

> 用途：为开场 / 总结 / 颁奖等环节生成可直接念的逐字稿。注意 talker 需全脱稿（彩排 2-3 次），所以稿子是"底稿"，不是念稿。

## 输入变量
- 发言人：{{executive}}
- 环节：开场致辞 / 总结致辞 / 颁奖致辞 / 其他
- 时长：{{minutes}} 分钟（约 {{words}} 字，按 200 字/分钟估算）
- 风格：{{tone}}（正式 / 轻松 / 激励）
- 场合背景：{{context}}

## 输出结构（逐字稿）
### 【开场】
各位同事，大家好。我是 ____。（{{suggested_title}}，需确认）
很高兴在 ____（场合）和大家见面。今天想聊三件事 ——

### 【主体，按目标分层选 2-3 点】
第一，____（战略定调 / 稳定军心）
第二，____（对大家的肯定 / 情感链接）
第三，____（关键战役 / Call to action）

### 【收尾】
____（金句 / 展望）。谢谢大家。

## 配套提醒（来自 SOP）
- 脱稿：talker 需全脱稿、流畅，彩排 2-3 次（原始数据）
- 时长控制：____ 分钟，现场控台举牌提醒
- 保密：如涉敏感，主持稿纪律段需含"不截屏录屏"（见 draft_host_script）
- 职位描述：（需确认）以秘书确认为准

## 标注要求
- 推断内容标（经验推断）；SOP 引用标（原始数据）；待补标（需确认）。
- 末尾附「需确认清单」。
