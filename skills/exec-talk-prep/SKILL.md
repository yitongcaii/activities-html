# 高管致辞 / 谈参 / 主持稿 准备助手

## 这个 skill 解决什么
文化活动里"写给人看的高管内容"是最难、最容易踩坑、又最高频的一环：
- 谈参写偏 → QA 环节答非所问 / 互相踢皮球
- 职位描述没和秘书确认 → 现场职位写错（如 CEO 写成 CE0）
- 主持稿没彩排 → 与控台配合卡、冷场
- 保密要求漏提 → 截屏录屏外泄

本 skill 把花草团队《文化类事件SOP&SLA》里散落的
「发言人稿件 / 高管谈参 / 高管照片 / 参会指引 / 主持稿 / 纪律保密」
抽成可复用结构，让你按场合 10 分钟产出一版可用初稿 + 把关清单。

## 数据来源
- path: references/extracted_data.json
- 来源文件：【花草团队】文化类事件SOP&SLA.xlsx
- 抽取 sheet：
  - 【第一步】厘清Why → audience_goals（目标分层）、activity_audience_map
  - 【第二步】持续完善的指引 → prep_sop（会前筹备）、host_script_elements（会中）、pitfalls
  - （持续补充）员工大会互动环节沉淀 → 暖场 / 数智人 / 互动导入

## 内容标注规范（重要）
输出必须区分来源：
| 标注 | 含义 |
|------|------|
| （原始数据） | 直接来自 SOP&SLA |
| （经验推断） | 基于文化活动筹备通用经验 |
| （需确认） | 需用户 / 高管秘书补充确认 |
| （案例参考） | 来自 SOP 的真实参考模板 |

> ⚠️ 严禁把推断伪装成原始数据。

## 使用场景
1. **写高管谈参**：「帮 Dowson 写员工大会谈参」 → 目标分层 + 要点建议 + 禁忌 + 职位确认
2. **写高管致辞**：「给 Wang 写 offsite 开场致辞逐字稿」 → 逐字稿 + 时长 + 风格
3. **写主持稿**：「员工大会主持稿，含纪律提醒和互动导入」 → 串词 + 环节衔接 + 互动
4. **把关清单**：「发言人稿件要检查什么」 → checklist（owner / SLA）
5. **坑点 / 资源查询**：「主持稿有哪些坑」 / 「数智人平台在哪」

## 工作流
1. **信息收集（关键）**：用 prompts/info_collection.md 反问，每次 ≤3 个。必收：
   - P0：场合（员工大会 / Offsite / 颁奖 / 团建）、高管（Dowson / Wang / GM / 线负责人）、目标
   - P1：时长、风格（正式 / 轻松）、是否线下+线上、是否有互动环节
   - P2：是否需要高管照片 / 职位描述确认、保密等级
2. **匹配场景**：谈参 / 致辞 / 主持稿 / 把关 / 查询
3. **读取** references/extracted_data.json 对应模块
4. **按 prompt 模板产出**，标注来源
5. **结尾给「需确认清单」**：职位描述、老板分工、保密口径、本人确认

## 输出形式
- 默认：Markdown 表格 + 结构化文本（对话中直接展示）
- 用户要求时，可输出纯文本稿供直接复制进腾讯文档 / KM

## 边界控制
- 高管职位描述、谈参口径必须标注（需确认），不得臆造
- 真实姓名 / 对接人默认脱敏，仅内部参考
- 保密要求（不截屏录屏）必须在主持稿纪律段出现
- 涉及真实高管发言内容，定稿前需经本人 / 秘书确认
