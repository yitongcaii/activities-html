# 谈参 · 一般员工大会（示例 / 脱敏）

> 本稿**仅用三样资产**生成：① 目标分层库 ② 核心信息四要素框架 ③ 致辞骨架。
> 已剔除：QA 预案 / 坑点检查 / 保密纪律段。
> 仅作资产库可用性评估样例，不含真实部门 / 人名 / 数据。

---

## 一、目标分层（勾选本场适用项）

- **员工侧**：稳定军心 ✅ ／ 鼓舞士气 ✅ ／ 战略传达 ✅
- **高管侧**：决策穿透力增强 ✅
- **部门侧**：战略解码加速 ✅ ／ 文化价值沉淀 ✅

---

## 二、核心信息四要素（本场谈参主心骨）

1. **战略定调**：结合阶段目标一句话定方向，不堆形容词
   → {一句话定方向} ｜如：下半年我们不打全面战，集中火力把 {主线产品} 做透
2. **对员工的肯定**：要具体到人 / 事，不空泛
   → {具体人/事} ｜如：上半年最让我踏实的是 {攻坚团队} 连熬三周把 {故障率} 压到 {x%}
3. **关键战役 / 里程碑**：点出最该被记住的一两件大事
   → {大事 1-2 件} ｜如：{出海版} 上线 ＋ {某认证} 拿下
4. **Call to action**：给一个可落地的动作或约定
   → {下一步动作} ｜如：每个人本周认领一个"提效一件事"小目标，月底复盘

---

## 三、谈参要点（给高管照着讲的提纲）

**开场**
- 先点名感谢 {某群体·如：一线支持同学}，一句话定调（对应要素 ①）

**主体（按目标分层选 2-3 点展开）**
- ① 稳定军心 ＋ 战略传达：讲方向、不讲虚词（对应要素 ①）
- ② 情感链接 ＋ 对员工的肯定：讲具体的人和事（对应要素 ②）
- ③ 关键战役 ＋ CTA：讲一件大事 ＋ 一个动作（对应要素 ③ ④）

**收尾**
- 一句金句 / 展望收口（对应要素 ④ 的延展）

---

## 四、致辞逐字稿（按致辞骨架生成 · 示例填充）

**开场**
各位同事，大家好。我是 {职位}。很高兴在 {场合·如：2026 年中员工大会} 和大家见面。今天想聊三件事——

**主体**
第一件，关于方向。{战略定调·如：下半年我们集中火力把主线产品做透，不在边缘线上分散兵力}。
第二件，关于人。{对员工的肯定·如：上半年最让我踏实的是攻坚团队连熬三周，把故障率压到了 x%}。
第三件，关于接下来。{关键战役·如：出海版上线 + 某认证拿下}，这件事大家记住就好。下一步，{CTA·如：每人本周认领一个"提效一件事"小目标}。

**收尾**
{金句/展望·如：路是对的，就不怕远}。谢谢大家。

> 备注：稿是底稿，需全脱稿、流畅，彩排 2-3 次；时长按 ~200 字/分钟估算，控台举牌提醒；职位描述以秘书确认为准。

---

## 五、本版"瘦"在哪（因只保留三样资产）

- ❌ **无 QA 预案**：编制 / 晋升 / 项目去留等敏感问题现场无口径护栏
- ❌ **无坑点检查**：职位错写（CE0）、念稿感、保密漏提等无防范清单
- ❌ **无保密纪律段**：不截屏录屏 / 静音 / 等候室等未提醒

> 结论：三样资产能产出**结构清晰、不跑题、有骨架**的谈参 ＋ 致辞底稿；
> 但缺"安全网"，适合**内部低风险场合**，高风险 / 敏感 QA 场合需补回 QA / 坑点 / 纪律。
