# 谈参 / 致辞 Draft · {领导} @ {场合}

> 本模板为**轻量版**：谈参结构 = 目标分层 + 核心信息四要素 + 致辞骨架（3 样资产）。
> 不含重型 QA 预案 / 坑点检查 / 保密纪律库——适合低风险内部场合（纯传达、无敏感问答）。
> 若场合涉及编制 / 晋升 / 项目去留等敏感 QA，请另行补充口径与护栏。

- 领导职位与姓名：`{职位}{姓名}`（**务必与秘书核对**，避免 CEO → CE0 类错误）
- 场合与受众：`{员工大会/Offsite/颁奖}`，受众关系 `{上下级 supervisor / 高管 exec}`
- 发言时长：`{X}` 分钟
- 保密范围：`{可截屏 / 禁录屏 / 禁外发}`（写进稿头）
- 必须提及的口径 / 红线：`{公司统一口径}`

## 1. 目标分层（参考 talk_prep_assets.json → target_layering，勾选本场适用项）
- 员工视角：`{如：稳定军心 / 鼓舞士气 / 战略传达}`

（主体 · 肯定）`{口语化肯定，1–2 句}`

## 5. 自检闸（交付前必过）
- [ ] 通读像领导本人念出来——顺、不书面腔
- [ ] 搜一遍：无 `(需确认)` `(示例)` `[引用iX]` 混入致辞正文
- [ ] 职位 / 姓名已与秘书确认（防 CE0 类错写）
- [ ] 保密范围已写进稿头
- [ ] 目标分层已勾选（1–3 个，不堆砌）
- [ ] 四要素齐全（定调 / 肯定 / 战役 / CTA），每要素占位 + 示例提示
- [ ] 受众关系匹配（上下级 = 尊重不暴露 / 高管 = 商务切入），无平级朋友向表达
- [ ] 所有 `{ }` 占位已汇总成待填清单交回用户

## 6. HTML 三色阅读版（强制输出，渲染规范）

遵循 `SKILL.md`「HTML 三色阅读版」规范，基于本稿 Markdown 生成一份 self-contained HTML：

- **句句换行**：致辞逐字稿每句话（以 。！？ 收尾）单独成一行，念稿一行一拍；`（舞台提示）` 用灰色小字单独成行或行内标注，不混三色。
- **三色标注**（仅阅读辅助，不改正文）：
  - 🟠 **橙色** = 有温度的语气词 / 口语共情句（大家真的不容易、错了算我的、难得凑这么齐…）。
  - 🔵 **蓝色** = 每一节标题（## 节标题）。
  - ⚪ **灰色小字** = 括号里的舞台提示 / 备注（（笑）（点头）（合影）等）。
- **页脚**：注明「颜色仅为阅读辅助标注，不影响正文」。**本 skill 生成的 HTML 一律不带 yitong 页脚**。
- 顶部**无图例说明块**，只留标题。
