# 真腔样本库（脱敏 · 供模仿语气，不带入私有信息）

> 来源：9 份真实文化活动主持稿，已去除部门 / 公司 / 人名 / 奖项，仅保留「语气质感」供模型模仿。
> 用法：生成主持稿时，参考这些句子的**呼吸感 / 共情 / 轻自嘲**来写，而非套用其具体词。
> 受众：全部上下级（supervisor）/ 高管（exec）向，无平级朋友向。

## 1. 开场破冰的温度（不端着）

- 平时大家都在一线连轴转，难得凑这么齐。今天不聊琐细，就聊一件事。
- 先把手机调成静音吧——咱们今天要聊点大事，别让通知声把灵感打断了。
- 今天有点特别，除了现场，线上各地的伙伴也都在。来，镜头两边，把手举起来挥一挥！

## 2. 承上启下的巧劲（不硬切）

- 如果说刚才 X 是从高度看主题，那接下来 Y 的分享，是把镜头拉回到具体层面。
- 刚才各组是从「方向」看这件事，接下来咱们把它拉回「动作」——棋路定了，落子才有准头。

## 3. 轻自嘲 / 人味（拉近距离不越界）

- 我这主持也就是个串场的，干货都在各位手里。
- 说错了大家多包涵，毕竟我比在座各位更擅长把简单的事说复杂。（笑）
- 平时大家都在业务一线连轴转，难得聚这么齐，今天不聊琐细。

## 4. 互动里的接话（show-don't-tell 的范本）

- 抽答后：这问题太典型了，咱们圆桌专门聊它。
- 看墙后：三个收获最后都指向同一个词——对齐。这就是今天最值钱的东西。
- 我念一张：收获——原来三个组都在抢同一类客户。你看，咱们不是各下各的，棋是连着的。

## 5. 颁奖的庄重与节奏（万能句 + 一句简介）

- 获得 XX 奖的是：……。请获奖代表上台。有请 X 领导颁奖，合影留念。
- 每轮口播一句话项目简介，分量递增，不抢获奖者风头。
- 连续颁奖时：X 领导请留步；单独颁发后：请 X 领导落座。

## 6. 结尾三件套的收束感

- 金句要落地而非喊口号：战略不是写在 PPT 里的，是走在每一步里的。
- 合照带一句温度：留张全家福，记一下这个时刻。（竞业同事可避让）
- 口号回扣主题，不另起炉灶：{主题口号}，{年份} 我们同行。

## 禁忌（去私有化后仍要避）

- 不写死任何真实部门 / 项目 / 人名 / 奖项。
- 不用平级朋友向梗（喝酒、互黑、暴露隐私、幼稚游戏）。
- 不堆排比、不书面腔、不把主持稿写成公文或舞台监督提示单。
