# references/errors.md — 完整错误码参考

| 码值 | 含义 | HTTP 状态码 | 处理建议 |
|-----|------|:---:|---------|
| `200` | 成功 | 200 | - |
| `40001` | Token 无效或缺失 | 401 | 检查 Token 是否正确，是否已过期 |
| `40002` | 参数错误 | 400 | 检查请求参数，如 sendTo 为空、文件为空、文件过大、MIME 类型不匹配等 |
| `40003` | 不支持的消息类型 | 400 | 检查 URL 路径中的消息类型是否正确 |
| `40004` | 端点未找到 | 400 | 检查 endpoint 参数是否正确；若确认 endpoint 无误，说明该机器人尚未接入 AgentHub 或未启用长连接，请参考 [接入指引](https://iwiki.woa.com/p/4018574532) 完成接入 |
| `40301` | 端点权限不匹配 | 403 | Token 与 endpoint 不匹配，请使用正确的端点 Token |
| `42901` | API 调用频率超限 | 429 | 降低请求频率，响应头包含 `Retry-After` 表示建议等待秒数 |
| `42902` | 推送频率超限 | 429 | 该会话推送过于频繁（单会话限 10条/分钟、100条/天），请稍后重试 |
| `50001` | 机器人未连接 | 503 | 机器人已接入但当前 WebSocket 连接断开（离线/重连中），请稍后重试；若持续出现，请联系管理员检查长连接状态 |
| `50002` | 消息发送失败 | 500 | 发送过程中出现异常，请查看 message 字段详情 |
| `50003` | 服务未就绪 | 503 | 服务正在启动中，请稍后重试 |
| `50101` | 媒体上传服务不可用 | 501 | 媒体上传服务暂不可用 |
| `20701` | 群发部分成功 | 200 | 部分目标发送失败，查看 results 字段详情 |
| `20702` | 群发全部失败 | 200 | 所有目标发送均失败，检查 endpoint 和目标是否有效 |
