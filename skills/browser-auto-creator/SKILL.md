# 浏览器自动化技能生成器

## 技能概览

录一次，永远用。在浏览器中演示一遍，即可自动生成可复用的自动化技能——无需写代码，开箱即用。

---

## 📌 请先选择您需要的模式

在开始使用前，请根据您的需求选择合适的模式：

### 🎯 模式一：精准路径复现
- **一句话描述**：自动执行固定的操作流程
- **适合场景**：网页结构稳定、操作步骤固定不变、需要反复执行同一套流程
- **特点**：页面稳定、操作步骤固定、精准复现每一步。生成以脚本为主的自动化技能包，技能使用token消耗少。
- **📖 查看详细文档**: [`references/browser_auto_precise.md`](./references/browser_auto_precise.md)

### 🧠 模式二：智能意图理解  
- **一句话描述**：帮助 AI 理解如何使用 Web 平台
- **适合场景**：让 AI 学会操作某个平台（如内部系统、第三方页面），通过手动演示一次，AI 自动分析，生成可复用的平台操作技能（如：教会 AI 如何在 TAPD 创建任务、如何在 KM 搜索文章）
- **特点**：页面可能变化、灵活操作、生成文档而非脚本。生成以md文件为主的自动化技能包，技能使用灵活。
- **📖 查看详细文档**: [`references/browser_auto_vague.md`](./references/browser_auto_vague.md)

**💡 提示**: 如果不确定选哪个，继续向下查看详细对比 ⬇️

## 🎯 模式选择指南

浏览器自动化技能生成器支持**两种模式**，适用于不同的自动化场景：

### 模式一：精准路径复现模式

**适用场景：**
- ✅ 页面结构稳定，不会频繁变化
- ✅ 用户操作流程固定，每次执行步骤相同
- ✅ 需要精准复现用户的每一个操作步骤
- ✅ 适合重复性强的固定流程自动化

**特点：**
- 🎯 **精准定位**：记录具体的元素选择器（ID、class、XPath）
- 🔄 **完整重放**：按录制的顺序和操作精确执行
- ⚡ **执行高效**：直接执行预定义的操作序列
- 📋 **适合批量**：适合批量执行相同的操作流程

**典型应用：**
- 表单自动填写和提交
- 数据批量录入
- 定时任务自动执行
- 重复性测试流程

**使用方式：** 查看 [`references/browser_auto_precise.md`](./references/browser_auto_precise.md) 文档

---

### 模式二：智能意图理解模式

**适用场景：**
- ✅ 页面结构可能变化，元素位置不固定
- ✅ 用户操作作为指引，不依赖特定路径
- ✅ 需要灵活应对页面变化和异常情况
- ✅ 适合探索性操作和智能交互

**特点：**
- 🧠 **意图理解**：不记录具体路径，而是理解用户的操作意图
- 🔍 **智能分析**：捕获用户操作和对应的 API 请求
- 📚 **文档生成**：生成 API 文档和操作指南，而非固定脚本
- 🎨 **灵活适配**：适应页面变化，无需依赖固定选择器

**典型应用：**
- 教会 AI 如何在 TAPD 创建任务、提交 Bug
- 教会 AI 如何在 KM 搜索和发布文章
- 教会 AI 如何在内部平台提交审批、查询数据
- 教会 AI 如何操作任意第三方 Web 平台

**使用方式：** 查看 [`references/browser_auto_vague.md`](./references/browser_auto_vague.md) 文档

---

### 如何选择？

| 对比维度 | 模式一：精准路径复现                  | 模式二：智能意图理解                |
|---------|-----------------------------|---------------------------|
| **页面稳定性** | 要求页面结构稳定                    | 可应对页面变化                   |
| **操作灵活性** | 固定步骤，精准执行                   | 理解意图，灵活操作                 |
| **实现方式** | 通过生成 Playwright 脚本达到生成浏览器操作自动化技能 | 通过生成 API 文档+操作指南达到生成浏览器操作自动化技能 |
| **执行方式** | 自动执行脚本                      | 需要 Agent 理解文档后执行          |
| **适用场景** | 重复性固定流程                     | 探索性和文档化需求                 |
| **维护成本** | 页面变化需重新录制                   | 文档更新相对容易                  |

**快速判断：**
- 🤔 "我需要每天固定时间执行相同的操作" → 使用**模式一**
- 🤔 "我需要让 AI 理解如何使用某个平台" → 使用**模式二**
- 🤔 "页面经常改版，选择器容易失效" → 使用**模式二**
- 🤔 "我需要批量处理大量相同任务" → 使用**模式一**
