# 风格档案（自动沉淀 · 最近更新：2026-08-06）

> 来源：用户一次性提供的往期文案，共约 13 篇，分三类——
> ① 活动前预热（英语角 1 + 沙龙 1）
> ② 活动群聊进行中（英语角 3 + 沙龙 6）
> ③ 活动完成后（英语角 1 + 沙龙 2）
> 覆盖活动类型：英语角、AI 实战沙龙（AI See）。渠道：企微群（@all、原生 QQ 表情）。

## 1. 结构范式
- 结论：**按"活动阶段"而非单次成稿**——同一活动会产出 预热→进行中(多波)→完成后 三段式序列，而非孤立一篇。每篇结构高度模板化：
  - **预热**：emoji 大标题钩子 → `@所有人`+[勾引] → 讲师/布道师背书 → 报名 CTA → `⏰时间 / 📍地点 / 📌主题 / 🔍简介` 用【】标签分行 → 附海报/材料预览。
  - **进行中（连发多条）**：时间紧迫钩子（"马上开始/还有5分钟/今天16:00就开始"）→ `@所有人` → 地点+茶歇/奖品提醒 → 线上链接；末段转"互动/实操挑战/有奖"。
  - **完成后**：小结大标题 → `⚡本期概览` → 材料&录屏回看链接 → 后续动作（提交作业/问卷打分/晒 demo）→ 奖品提醒。
- 证据：
  - 预热沙龙：「🔥第x期｜AI实战沙龙来啦！@所有人 [勾引]本期邀请了…布道师…欢迎点击速速报名！！！⏰【x月x日（周x）19:00】📍【xxxx】📌【主题】🔍【简介】」
  - 进行中沙龙4：「🔥沙龙即将开始啦！📍线下地点-【xxxxxx】…🔗线上链接：」
  - 完成后沙龙1：「[坏笑]本期沙龙圆满结束啦！[庆祝]…【附问卷链接】[烟花]最后欢迎大家对本期沙龙打个分！👇」

## 2. 语气与口头禅
- 基调：**活泼、高密度 emoji + 原生 QQ 表情（[庆祝][坏笑][机智][呲牙][让我看看][666] 等）、网络化口语**。用户已确认"网络化可以接受"，与早期模板假设的"不网络化"相反——本档案如实记录真实调性。同时用户新增硬约束：**必须礼貌得体、无歧义**；其中 `[勾引]` 在正式群/有领导在的群属易误读表情，默认规避，改用 [庆祝]/[烟花] 等中性表情。
- 惯用连接词 / 收尾句：「来啦」「速速报名」「抓紧上车」「一起提效，一起冲！！！」「边学边练，边练边成长」「带电脑，现场实操」「茶歇等着大家」「奖品数量有限，先到先得」「欢迎随时在群聊或线上评论区举手噢」。
- 高频收尾动作：`@所有人`（几乎每篇必带）、"欢迎大家…"。
- 证据：
  - 「未报名的同学抓紧上车噢[坏笑]」「戳链接报名，和哑巴英语 say goodbye！👇👇」
  - 「我们线上聊AI，线下练实操，一起提效，一起冲！！！[666][666]」

## 3. 钩子类型
- 预热：利益/背书钩子（"精彩不停""AI实战沙龙来啦" + 布道师头衔）+ `@all`。
- 进行中：时间紧迫钩子（"马上开始""还有5分钟""今天16:00就开始啦"）。
- 完成后：成就+奖品钩子（"圆满结束""完成 Demo 有奖""随机抽取送出惊喜周边"）。
- 可复用模板句式：
  - 预热：「🔥第x期｜{活动名}来啦！@所有人 [勾引]本期邀请了{部门}{头衔}，带你{价值点}」
  - 进行中：「📢📢还有5分钟，第x期【{活动}】就开始啦，大家快来吧～～@所有人」
  - 完成：「[坏笑]本期{活动}圆满结束啦！[庆祝]感谢…【附问卷链接】」

## 4. 禁用与偏爱词
- 刻意避开：未主动禁用词；但**实际未使用"赋能/闭环/抓手/一站式"等套话**，保持口语化、具体动作化（"实操""跑 demo""沉淀到知识库"）。
- 高频偏爱：🔥📢⚡🎯⏰📍🎉[庆祝][坏笑][勾引][机智][呲牙][让我看看][666][烟花][啤酒][太阳]；"布道师""实操""茶歇""奖品/惊喜礼品""上车""冲""速速""材料包"。
- 证据：「本期邀请了安全产品x部的xxxxx布道师」「带上电脑，深圳现场实操」「领取幸运奖品噢🎁」「完成demo有奖 | 前5位」

## 5. 结尾引导（CTA）
- 预热：👉 报名链接（"戳链接报名""点击速速报名"）。
- 进行中：@all + 地点/茶歇/奖品 + 线上链接；末段转"互动/实操挑战/有奖"（如"#完成实操，获得惊喜奖品# 前5位有奖"）。
- 完成后：回看链接（材料&录屏）+ 作业提交指引（英语角：录音发指定邮箱名单）+ 问卷/打分 + 奖品提醒（"前5名完成可以获得惊喜礼品"）。
- 模板：「👉【沙龙实战材料包】… ⚡【本期沙龙概览】… 🔗线上链接：」

## 6. 字数区间与渠道适配
- 预热：约 100~200 字/篇（沙龙偏长，含简介）。
- 进行中：短促，50~150 字/条，按时间节点连发多条（非单篇）。
- 完成后：150~250 字/篇。
- 渠道：企微群原生环境——`@所有人`、QQ 表情 `[xxx]`、emoji 混用；海报/图片以"（附海报）""（附图片）"占位。

## 7. 套用提示（给下次生成用）
- 默认语气：活泼 + emoji/QQ表情密集 + 网络化口语 + 每篇必带 `@所有人`；**默认遵守"礼貌得体、无歧义"红线**（模糊时间给具体日期、易误读表情[勾引]规避、人名品牌前后一致、零错字）。
- 默认版本/侧重点：**按阶段出序列**——预热出"讲师背书版"+"内容价值版"两版；进行中按"开场提醒/茶歇奖品/互动有奖"出 3~6 条；完成后出"小结+回看+作业/问卷"一版。
- 默认钩子：预热用背书/利益；进行中用时间紧迫；完成用成就+奖品。
- 默认结尾 CTA：预热带报名链接；进行中带 @all+地点/线上链接+有奖；完成带回看+作业或问卷+奖品。
- 两类活动差异：英语角强调「茶歇/线上接入/录屏回看/提交英语录音至指定邮箱名单」；沙龙强调「布道师/线下带电脑实操/材料包/Demo有奖/知识库沉淀/问卷打分」。
