# 输出格式规范

## 双交付总则

每次调研产出两份文件：
1. **HTML 卡片墙**（主展示，优先给用户预览）
2. **Markdown 表格**（数据版，可直接进 Obsidian）

两份文件内容必须一致，只是格式不同。

---

## HTML 卡片墙规范

### 文件命名

`{主题}-org-map.html` 或 `{主题}-talent-map.html`，ASCII 文件名（如需推 GitHub Pages 禁用中文名）。

### 视觉风格

| 属性 | 规格 |
|------|------|
| 主色调 | 紫青双色渐变（`#7C3AED` → `#06B6D4`） |
| 布局 | Bento Grid 卡片墙，等列等高 |
| 卡片 | 圆角 16px + 柔和投影 `0 4px 12px rgba(0,0,0,0.08)` |
| 背景 | 浅灰 `#F8FAFC` 或纯白 |
| 分类标签 | Pill 胶囊式（Soft UI 风），按行业/业务线着色 |
| 置信度标签 | 高=绿 / 中=橙 / 低=红（带"需人工核实"文字） |
| 字体 | 系统默认无衬线，标题 600 weight |

### 页面结构

```
1. 顶部标题区
   - H1 标题（如"字节跳动组织架构人才地图"）
   - 副标题：采集日期 + 采集范围说明 + 数据量统计
   - 筛选器：行业/业务线下拉 + 置信度下拉

2. 统计概览区（可选）
   - 总人数 / 业务线数 / 高置信条目数 / 需确认条目数

3. 卡片墙主体
   - 每张卡片：姓名(标题) + 职位(副标题) + 团队(Pill标签) + 简介(2-3行) 
   + 来源链接(可点击) + 采集日期 + 置信度标签

4. 关系网络区
   - 文字描述形式列出关系链
   - 格式: A →(关系类型)→ B
   - 每条关系标置信度

5. 缺口提示区
   - 列出所有"需确认"和"低·需人工核实"的条目
   - 登录墙源说明
   - 时效性提醒
```

### 交互功能

- **筛选**：按行业/业务线筛选 + 按置信度筛选（可组合）
- **搜索**：按姓名/职位关键词搜索（可选）
- **来源链接**：每条卡片的来源链接可直接点击跳转

### 页脚

```html
<p style="text-align:center;color:#94A3B8;font-size:12px;margin-top:40px;">
  📌 本页由 yitong 沉淀整理 · 人才情报库 | 采集日期: {YYYY-MM-DD}
</p>
```

## Markdown 表格规范

### 文件命名

`{主题}-org-map.md` 或 `{主题}-talent-map.md`，可使用中文名（Obsidian 友好）。

### 文档结构

```markdown
# {标题} 人才地图

> 采集日期: {YYYY-MM-DD} | 采集范围: {说明} | 数据量: {N} 人
> 源: 联网实搜 + 多源交叉 | 口径: 只采公开可查，不编不猜

## 一、岗位分布

### {业务线/团队名}（{N}人）

| 姓名 | 职位 | 所在团队 | 公开简介 | 来源链接 | 采集日期 | 置信度 |
|------|------|---------|---------|---------|---------|--------|
| ... | ... | ... | ... | [来源](url) | YYYY-MM-DD | 高/中/低 |

（每个业务线一个子章节）

## 二、关系网络

| 关系 | 类型 | 说明 | 置信度 |
|------|------|------|--------|
| A → B | 上下级 | A 向 B 汇报 | 高 |
| A ↔ C | 同事 | 同在 XX 部门 | 中 |
| B → D | 权力消长 | B 接管 D 的业务线 | 高 |

## 三、缺口与待确认

- **{人名}**: {矛盾/缺失说明} → 需人工核实
- **{领域}**: 只搜到招聘JD，无公开具名现任负责人 → 需确认
- 脉脉/领英/小红书个人主页为登录墙，未能直采
- 此为 {YYYY-MM-DD} 采集时点公开源快照，部分岗位可能已变动
```

### 字段填写规范

| 字段 | 规范 |
|------|------|
| 姓名 | 全名；重名加括号区分（如"张楠(Kelly,女)" / "张楠(男,UG)"） |
| 职位 | 公开报道中的职位全称，不简化 |
| 所在团队 | 业务线/部门名，与岗位分布章节一致 |
| 公开简介 | 1-2 句：履历亮点 + 公开演讲/报道关键信息 |
| 来源链接 | 可直接访问的完整 URL；多个源用分号分隔 |
| 采集日期 | YYYY-MM-DD 格式 |
| 置信度 | 高 / 中 / 低·需人工核实（低必须带说明） |
