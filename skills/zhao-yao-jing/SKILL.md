# 照妖镜 (Zhao Yao Jing)

多维度深度分析工具，照出问题的各个角度和隐藏的真相。

## 核心能力

### 多学科思维框架

- **Charlie Munger 风格思维**：应用多学科心智模型进行分析
- **逆向思维分析**：通过反向思考识别失败模式和风险
- **系统思维**：识别杠杆点和反馈循环
- **盲点发现**：揭示隐藏的假设和未被注意的风险
- **创新机会探索**：发现潜在的突破点和创新方向

## 分析维度

分析时应从以下五个核心维度进行思考：

### 1. 心理学视角
- 认知风格评估
- 认知偏差识别（确认偏误、锚定效应、可得性偏差等）
- 行为模式分析

### 2. 行为经济学视角
- 激励机制设计
- 显性偏好 vs 隐性偏好分析
- 损失厌恶分析

### 3. 社会学视角
- 角色理论分析
- 社会资本评估
- 网络效应分析

### 4. 系统思维视角
- 反馈循环映射
- 杠杆点识别
- 飞轮效应设计

### 5. 商业战略视角
- 竞争优势分析
- 护城河评估
- 单位经济模型

## 分析方法

### 逆向思维（Pre-Mortem）

在进行分析时，首先假设项目/决策已经失败：

1. 生成 3-5 个最可能的失败场景
2. 对每个场景进行因果链分析
3. 识别早期预警信号
4. 设计预防措施

### 盲点发现

应用 Johari 窗口模型识别：

1. 已知-已知区域（公开区）
2. 已知-未知区域（盲点区）- 重点关注
3. 未知-已知区域（隐藏区）
4. 未知-未知区域（未知区）

### 杠杆点识别

寻找可以产生最大影响的干预点：

1. **优势考古学**：挖掘过去成功经验中的核心要素
2. **隐藏资产清单**：识别未被充分利用的资源
3. **休眠能力评估**：发现被遗忘或低估的能力
4. **独特组合分析**：寻找独特的资源/能力组合

## 使用场景

### 适合使用此 skill 的情况

1. **重大决策前的全面评估**
   - 新产品功能规划
   - 架构选型决策
   - 战略方向选择

2. **多角度战略分析**
   - 项目可行性评估
   - 风险全面识别
   - 机会发现

3. **复杂问题的深度思考**
   - 决策困境突破
   - 系统性问题分析
   - 创新方向探索

4. **个人/团队发展规划**
   - 能力发展路径设计
   - 成长瓶颈识别
   - 优势放大策略

### 不适合使用的情况

- 简单的技术问题（如语法错误修复）
- 明确的单一答案问题
- 不需要权衡的执行性任务

## 输出格式

分析报告应包含以下结构：

### 1. 执行摘要
简要概述主要发现和关键建议（3-5 句话）

### 2. 多维度分析
按五个核心维度展开分析，每个维度：
- 关键洞察
- 风险/机会识别
- 相关证据或案例

### 3. 逆向思维分析
- 失败场景列表
- 预警信号
- 预防措施

### 4. 盲点发现
- 识别的盲点
- 潜在影响
- 应对建议

### 5. 行动建议
按优先级排序的具体建议：
| 优先级 | 建议 | 预期影响 | 实施难度 |
|--------|------|----------|----------|
| P0 | ... | ... | ... |
| P1 | ... | ... | ... |

### 6. 关键指标
建议追踪的度量指标

## 分析工作流程

执行分析时遵循以下流程：

1. **理解上下文**
   - 收集背景信息
   - 明确分析目标
   - 识别约束条件

2. **多维度扫描**
   - 依次应用五个分析维度
   - 记录每个维度的关键发现

3. **深度挖掘**
   - 对关键问题进行逆向思维分析
   - 进行盲点发现
   - 识别杠杆点

4. **综合整合**
   - 交叉验证各维度发现
   - 识别模式和矛盾
   - 形成整体视图

5. **生成建议**
   - 提出可执行的行动建议
   - 设计度量指标
   - 优先级排序

## 最佳实践

### 分析深度控制

根据问题复杂度调整分析深度：

- **轻度分析**（15分钟级）：快速扫描所有维度，聚焦最相关的 2-3 个
- **标准分析**（30分钟级）：全面覆盖所有维度和方法
- **深度分析**（60分钟级）：包含外部研究、历史案例对比

### 输出调整

根据受众调整输出：

- **执行层**：聚焦行动建议和关键指标
- **战略层**：强调系统分析和长期影响
- **技术层**：提供更多实施细节

## 注意事项

1. **分析过程可能较长**：深度分析需要时间，保持耐心
2. **输出内容丰富**：报告内容详尽，建议分阶段消化
3. **迭代改进**：随着情况变化，定期重新评估
4. **避免分析瘫痪**：分析是为了更好地行动，不是替代行动
