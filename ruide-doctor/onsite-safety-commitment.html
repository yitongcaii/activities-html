进场人员（安全 · 保密）承诺书

适用于非劳动关系进场人员（实习 / 外包 / 劳务 / 兼职 / 退休返聘等）

本人因 【项目合作 / 实习 / 劳务服务 / 其他】 需要进入 【公司全称】（下称"公司"）办公、研发、生产或实验场所，或使用公司系统、设备、数据。为明确双方关系与责任边界，本人自愿签署本承诺书。

承诺内容

  1. 现场安全：遵守公司现场安全管理规定，包括药品生产 / 实验区域准入、个人防护用品穿戴、设备操作规范、消防与应急要求；未经许可不进入受限区域、不操作非授权设备。
  2. 保密义务：对接触到的公司药品配方、生产工艺、检测数据、客户（宠物医院与渠道）信息、经营信息等保密信息严格保密；不拍摄、复制、下载、外传，不用于任何与公司无关的用途。离场后保密义务持续有效。
  3. 基本行为规范：遵守公司基本公共秩序与行为规范，不从事损害公司利益或声誉的行为。
  4. 关系确认（核心）：本承诺书仅约束本人在公司场所 / 系统内的安全与保密行为，不构成本人与公司之间的任何劳动关系、劳务关系或雇佣关系。本人知晓：本人的工资报酬、社会保险、工伤、工时等权利义务，由其签约主体（如外包公司、学校、劳务公司等第三方）依据其与本人的协议承担，与公司无关。
  5. 违约后果：如违反上述承诺，公司有权立即终止本人的进场权限、拒绝其进入场所；造成公司损失的，公司有权依法及依相关协议追究赔偿责任。
