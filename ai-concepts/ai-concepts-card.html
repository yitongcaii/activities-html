AI 协作概念卡

六个词，看一遍就懂 · 点开卡片看比喻和例子
先把 AI 想成你的数字搭档 / 实习生。你天天在 WorkBuddy 里撞见的词，其实就是它身上的几样装备—— 说话、卡、插头、黑框、定时。下面六张卡，每张一句话讲清它是啥、像啥、跟别的啥关系。
💬
Prompt
提示词
沟通 · 一次性
你随口跟实习生说的那一段话。
展开：比喻 / 例子 / 关系
像啥：你临时给实习生布置任务说的那句要求，说完这次就完了，不存。
例子："给张三写封婉拒邮件，语气客气、别太长。"
关系：只做一次用 prompt 就够了；发现要做第二遍，就该升级成 skill。
📇
Skill
技能 / 标准作业卡
沟通 · 可复用
你贴实习生桌上的标准作业卡，下次直接说"按卡做"。
展开：比喻 / 例子 / 关系
像啥：把"怎么做"写进一张卡存起来，换会话换项目还能用，AI 自动加载。
例子：你建的「腾讯会议纪要」skill——建会改会取纪要一套流程存好，随时叫。
关系：skill 内部往往就是塞好的一段段 prompt + 模板 + 工具红线；是 prompt 的"升级收纳盒"。
🔌
MCP
连接器 / 外部插头
能力 · 授权
给 AI 开的"外接插头"，插上它才能碰你公司系统。
展开：比喻 / 例子 / 关系
像啥：AI 本来只会动嘴，MCP 是给它开的外部系统权限——插"企微"能发消息，插"腾讯会议"能建会。
例子：连接器列表里的「企微 disconnected」= 插头没装，AI 用不了；点亮信任 = 装好插头。
关系：MCP 是盖在 API 之上的"AI 专用标准插头"，它底下调的就是各系统的 API。
⌨️
CLI
命令行
操作 · 黑框
不点鼠标，改成打字写一行指令让电脑照做。
展开：比喻 / 例子 / 关系
像啥：平时你用手指点图标（看着点）；CLI 是写张纸条递给管家「关灯·锁门·倒垃圾」，它按顺序做。
例子：AI 说"跑这个脚本汇总表格"，给你一行字，你打开黑窗口粘贴回车就出结果。
关系：你基本不用自己写命令，AI 生成好给你；CLI 是 AI 在你电脑上真正"动手"的方式之一。
🪟
API
接口 / 软件隔窗点单
底层 · 通道
两个软件之间"隔窗点单、互相传话"的通用通道。
展开：比喻 / 例子 / 关系
像啥：天气 APP 不是自己测的，是给气象局发"北京啥天？"气象局回"晴26度"——这来回就是 API。
例子：扫码支付、查快递、登录授权，背后全是 API，你天天用但看不见。
关系：API 是地基（大类别），MCP 是给 AI 接这些地基的"国标插头"；不是 API 包含 MCP，是 MCP 调用 API。
⏰
Automation
自动化 / 定时任务
运行 · 不盯
你定"每天10点做XX"，电脑自己跑，不用你盯。
展开：比喻 / 例子 / 关系
像啥：给管家设了个闹钟任务，到点自己干，不用你每次提醒。
例子：你已有的每6小时知识采集、每天10点英语角提醒，都是 automation。
关系：automation 是"什么时候跑"，跑的内容往往是某个 skill / prompt；定时 + 卡 = 全自动。
