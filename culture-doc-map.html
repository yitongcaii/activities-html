文化活动文档地图

员工大会 × Offsite —— 两套活动，各自的 SOP / Rundown / Checklist 三件套
⚠️ 关键区分：SOP / Rundown / Checklist 是「同一场活动」的三种配套文档（流程规范 / 当天剧本 / 打勾清单）； Offsite 是另一种活动类型，不是员工大会的"第四种文档"。它内部同样有自己的三件套。

📣 员工大会

对外扩 · 全员

SOP 标准流程

标准作业流程：定义「怎么做、谁负责、做到什么程度」。零 Why → 会前(内容/运营) → 环节参考 → 会中 → 会后。

文件：员工大会SOP.md

Rundown 当天剧本

大会当天的分钟级流程表（时间/环节/负责人/时长），现场控台控场用，每次都不同。

由 SOP 要求会前制作

Checklist 打勾清单

把 SOP 关键项抽成打勾项，会前逐条核验防遗漏（当前偏设备/现场风险）。

文件：员工大会会前检查清单Checklist.md

🧭 Offsite

向内收 · 小圈

SOP 标准流程

标准作业流程：零 Why(目的选型) → 会前(设计优先/运营) → 环节库 → 会中(引导) → 会后(跟进回溯)。

文件：OffsiteSOP.md

Rundown 当天剧本

1 日示例：开场立规→图景共享→战略对齐→午餐→研讨→脱口秀→挑战/跑步→承诺墙。能量曲线设计。

来源：知识库模块典型 Rundown

Checklist 打勾清单

会前核验「人要对 / 有前置 / 有产出 / 有跟进」四条设计层红线，尤其异地 logistics 红线。

文件：OffsiteChecklist.md

🆚 两套活动的核心区别

维度员工大会Offsite
目的传达 / 表彰 / 声量对齐 / 融合 / 解决真问题
规模大（全员，线上线下）小（核心圈 10–40）
形态一对多讲多对多共创
HRBP 角色执行统筹设计 + 引导（退幕后）
产出情绪 + 记忆行动项 + 共识
价值点当天散场后 90 天
🔗 组合打法：先 Offsite 让核心圈对齐方向 → 再员工大会向全员广播成果
