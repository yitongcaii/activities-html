# 训练集语料 · 抽象化场景摘要（去私有化）

> 本文件是 9 份真实文化活动主持稿的**抽象化**摘要，已去除所有具体部门名、公司项目名、真实人名。
> 目的：作为 few-shot 语料，帮助理解每类活动的**真实编排节奏与方法论**。
> 详细可复用资产见 `asset_library.json`。

## 语料来源说明

- 原始素材：9 份文化活动主持稿（1 PDF + 8 DOCX），覆盖员工大会 / 干部 Offsite / 专项颁奖三类。
- 时间跨度：2021–2026，趋势从「总结表彰」演进到「战略对齐 + 主题化 + 强互动」。
- 抽象原则：保留**结构、话术模式、互动手法、衔接逻辑**；剔除一切私有标识（部门、项目、人名、奖项名）。

## 三类活动 · 抽象化标杆结构

### 1. 员工大会（标杆：现代双人脱口秀式 + 强互动 + AI/数智人物料）

- **开场**：静音提醒 → 候场音乐/暖场视频 → 双主持自介（带轻自嘲人设）→ 异地多城市挥手打招呼 → 阐明主题（不仅是回顾，更是对齐方向）。
- **领导战略**：引介最高领导做全局战略指引；用「承上启下」句式引介下一位（从集团高度 → 拉回产品线）。
- **业务 Talk**：每条产品线一位 talker 讲真实故事；主持用「引介→总结→互动」三段式串场；负责人上台做简短规划 + 扫码猜愿望互动（前 N 名有礼）。
- **能力篇**：从业务故事过渡到后端能力（攻防/技术），用篇章标题「能力护航篇」衔接。
- **高管压轴**：最高领导发「补给包」+ 简单追问（对才艺/对主持的感受），拉近距离但不越界。
- **荣耀时刻**：荣誉视频 → 部门奖多轮（念名单→上台→颁奖→合影→留步）→ 安全线/公司BG奖（分量递增，高管颁奖）。
- **结尾**：金句 → 全家福合照提醒（提示竞业同事避让）→ 主题口号回扣 → 晚宴/散场指引 + 场外趣味活动。

### 2. 干部 Offsite（标杆：研讨 + 沉淀导向）

- **暖场**：轻量破冰（异地/年轻梗），不暴露隐私。
- **热身**：目标对齐，问卷 flag 抽签收集观点。
- **主题研讨**：分组圆桌，每组出 Slogan + 1-10 信心指数，聚焦战略共识。
- **沉淀**：便利贴 3-2-1（3 收获 / 2 行动 / 1 开放问题）贴墙，形成可执行结论。
- **总结**：高管收束，回扣战略主题。
- **文化礼物**：定制扇子/纪念物写祝福，建信任不越界（上下级向）。

### 3. 专项颁奖（标杆：纯颁奖模块 + 成效数据）

- **铺垫**：荣誉视频 + 获奖项目成效数据（量化成果，营造分量）。
- **部门奖**：多轮颁发，每轮「念名单→上台→颁奖→合影→留步」，口播一句话项目简介。
- **公司/BG 奖**：分量递增，高管颁奖，旁白提炼战报金句。
- **高管致辞**：寄语 + 感谢合作伙伴（QA/测试/设计/HR 等）。
- **庆祝**：蛋糕 / 合照 / 口号收尾。

## 通用规律（跨活动复用）

1. **静音提醒 9/9 通用**：开场第一句固定动作。
2. **异地打招呼是破冰标配**：多地点参会必做。
3. **颁奖句式高度统一**：念名单→上台→颁奖→合影→留步，可连续套用。
4. **结尾三件套**：金句 + 合照 + 主题口号，强化记忆。
5. **互动必有「扫码/转盘/埋卡」等低门槛动作**，且均为上下级/高管向，无平级朋友向内容。
6. **衔接靠「篇章标题 / 承上启下句式 / 主题回扣」**，而非生硬切换。
