# host-talk-prep · 文化活动主持稿 + 高管谈参助手（通用版）

给活动组织者 / HRBP 用的准备助手。基于 9 份真实文化活动主持稿抽象出的通用方法论，**已去除任何具体部门名、公司项目名**，可放心分发给同事复用。

> 需要带本厂真实腔调的内部版？请用 `exec-talk-prep`（个人私有 skill），本通用版不碰私有数据。

## 一句话定位

文化活动里最高频最难的两类交付——给人看的「高管谈参 / 致辞」和主持人要念的「串词」。本 skill 基于 9 份真实主持稿抽象成通用资产库，10 分钟出初稿 + 把关清单；双模块（主持稿 A / 谈参 B），去私有化、供同事复用。

## 能力全景（7 段结构）

### 1. 触发场景（关键词清单）
- **模块 A · 主持稿**：主持稿 / 串词 / 颁奖主持 / Offsite 主持 / 双人主持 / 员工大会主持
- **模块 B · 谈参**：谈参 / 高管谈参 / 发言要点 / 致辞稿 / 大会纪律提醒

### 2. 核心方法论（结构化）
- **两遍生成引擎**：规划层（套骨架 / 选互动 / 定隐喻 / 设计情绪起伏）只在内部完成、不打印；交付层只给干净稿。解决了早期"满屏括号、冷冰冰"的毛病。
- **模块 A · 主持稿**：8 节骨架（暖场 → 开场点题 → 领导致辞 → 业务 Talk → 能力篇 → 高管压轴 → 荣耀时刻 → 结尾三件套）；互动只选 `supervisor / exec` 向，自动剔除 `peer`；支持**双主持脱口秀式变体**（甲乙分工 + 隐喻贯穿全篇）。
- **模块 B · 谈参（轻量 3 样）**：目标分层库 + 核心信息四要素（定调 / 肯定 / 战役 / CTA）+ 致辞骨架（开场 / 主体 / 收尾）。
- **双产物**：每个模块都给 Markdown 干净稿 + HTML 三色阅读版。

### 3. 约束 / 避雷清单
- ❌ 不产平级朋友向（peer）内容
- ❌ 不杜撰：未给信息一律 `{ }` 占位 + `｜如：` 示例提示
- ❌ 零元标注（稿面无"（模板）""（示例）"等记号）
- ✅ cue 舞台提示单独成行
- ✅ 隐喻贯穿全篇
- ✅ 混合会场用**双向挥手**（镜头两边挥），禁单向"让我们看见你"
- ⚠️ 领导职位、保密要求需人工与秘书确认
- ✅ 必过自检闸 + 必出 HTML 三色
- 📌 **HTML 阅读版不带 yitong 页脚**（统一「颜色仅为阅读辅助标注，不影响正文」）

### 4. 案例 ×N
- 随包样例 4 份：双主持稿 / 单主持稿 / 谈参 demo + 两份三色 HTML 标杆（`examples/`）
- 实测员工大会 / 颁奖 / Offsite 三场景共用同一框架，证明**零场景锁入**

### 5. 边界与依赖
- **依赖**：通用 LLM 即可，把 `host-talk-prep/` 放进 `~/.workbuddy/skills/` 重启生效
- **不适用**：平级朋友向破冰；涉及编制 / 晋升 / 项目去留等敏感 QA 的高风险场合（谈参轻量版无护栏）；对外正式发布稿需人工复核

### 6. 配套资源（路径指向）
- `examples/`（4 份）：双主持稿、单主持稿、谈参 demo + 两份三色 HTML 标杆
- `references/`：`asset_library.json`（主持稿资产）、`talk_prep_assets.json`（谈参 3 样）、`raw-corpus/`（7 份脱敏原始稿）、`corpus.md`、`voice_samples.md`、`save_scene.md`
- `prompts/`：`draft_host_script.md`（含双主持变体）、`draft_talk_prep.md`
- 根：`SKILL.md`（入口 + 硬规则兜底）、`README.md`（本文件）

## 上手速查（给同事）

### 它能帮你做两件事

| 模块 | 一句话 | 你说的话（触发词） |
|------|--------|--------------------|
| **A. 主持稿** | 产出可直接彩排的干净串词（单主持 / 双人脱口秀式） | 「写一份{部门}员工大会主持稿，主题{主题}」「双人主持的颁奖串词」 |
| **B. 谈参** | 给高管准备发言要点 + 致辞逐字稿 | 「给{领导}准备一份{场合}谈参」「写一段{场合}高管致辞稿」 |

### 用之前，准备好这些参数（越多越准，不给就出占位稿）
- **主持稿**：活动类型（员工大会 / Offsite / 颁奖）、主题、口号、现场城市、线上城市列表、领导列表、产品线 / Talker 列表、奖项列表
- **谈参**：领导职位与姓名、场合、主题、受众关系（上下级 / 高管）、发言时长、保密范围、公司统一口径

> 不给真实信息也没关系——AI 会全部用 `{ }` 占位 + `｜如：` 示例提示，绝不编造真实活动。

### 你会拿到什么
每个模块都给**两份**，内容一致：
1. **Markdown 干净稿** —— 直接看 / 打印手卡
2. **HTML 三色阅读版** —— 句句换行方便念稿；🟠 橙=温度语气、🔵 蓝=节标题、⚪ 灰=括号提示（颜色只是辅助，不改字）

### 怎么填占位符
- `{主题}` `{领导姓名}` `{城市}` 这类是真的未知项 → 你填真实值
- `｜如：破局→棋局 / 航线` 这类是**写法示范** → 照着改，不冒充真实活动
- 稿末有「📝 待填清单」汇总所有占位，交回填写即可

### 脱敏原始语料（raw-corpus/）
随包附带 9 份原始主持稿（其中 1 份扫描件 PDF 无法自动脱敏未纳入，实际 7 份 docx）。部门 / 公司 / BG 已脱敏为 `{部门}` / `{公司}` / `{BG}`；**文中人名为原稿真实姓名，仅作语气 / 结构参考，对外发布前请自行替换为 `{姓名}` / `{领导}`**。这是给「想看真实稿长什么样」的人对照资产库用的，不是成品模板，不宜直接对外转发。

### 边界（什么时候它不适用）
- ❌ 平级朋友向破冰 / 团建（peer）—— 本 skill 不产出此类内容
- ⚠️ 谈参为**轻量版**（目标分层 + 四要素 + 致辞骨架），不含 QA 预案 / 保密纪律库。涉及编制、晋升、项目去留等敏感问答的场合，请另行补充口径与护栏
- ❌ 不写死任何真实部门 / 人名 / 项目，人工所有权始终在你
