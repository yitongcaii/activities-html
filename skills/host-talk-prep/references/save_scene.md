# 救场话术库（临场口头短句 · supervisor / exec 向）

> 用法：主持人现场遇到意外时的口头救场句。温和不抢戏、不冷场、不越界。
> 全部上下级 / 高管向，无平级朋友向。说完立刻回到流程，不展开。

## 冷场 / 无人响应

- 抛砖：我先抛一块砖——要是只能写一句，你会写什么？
- 降门槛：不想说的就写，不点名，咱们看墙就行。
- 自答示范：比如我会写「希望少点会、多点时间干活」，哈哈，开个头。

## 超时 / 临近饭点 / 领导讲长

- 温和收：您刚才那几句，其实就是把今天的棋盘最后点了一遍目。
- 留白：这一手咱们先留到会后再细推，今天先把方向摆开。
- 催场：给各组 2 分钟收个尾，咱们准时吃饭不耽误。

## 尖锐 / 负面回答

- 接纳：这问题很实，记进「开放疑问」那栏，回去专人跟。
- 转正面：痛点说出来了，其实也就是咱们今天要破的局。
- 不辩：这个口径我不当场接，会后我找你单聊。

## 设备 / 视频卡

- 从容：大屏先歇会儿，咱们先聊着，它好了再继续。
- 兜底：线上的伙伴如果听不清，公屏扣个 1，我慢一点。

## 情绪过低 / 过高

- 低：今天聊的有点沉，正常——说明咱们聊到真问题了。
- 高（过热争论）：这个议题值得，但咱们先记下来，圆桌专门掰。

## 禁忌

- 不嘲讽、不点名批评、不替领导改口、不玩笑化敏感话题。
- 救场句说完立刻回到流程，不展开。
