# 文化活动SOP助手 — 使用说明书

> 基于《【花草团队】文化类事件SOP&SLA》封装，帮助 BP/ABP/活动组织者高效筹备各类文化活动。

---

## 一、简介

这个 Skill 是一个文化活动筹备智能助手，覆盖从活动策划到执行落地的全流程。核心能力：

- **场景分析** — 根据部门状态推荐适合的文化活动
- **方案生成** — 输出完整的筹备方案（时间线 + checklist + 案例 + 风险）
- **环节查询** — 回答"QA问卷怎么设计""技术联调是什么"等具体问题
- **资源匹配** — 提供游戏、BGM、模板、工具等资源链接
- **文档输出** — 生成 Word / Excel / HTML 统一筹备文件

---

## 二、安装方法

### 方式一：自动安装（推荐）

1. 将 `culture-event-sop.zip` 发给需要使用的同事
2. 对方解压到 WorkBuddy 的 skills 目录：
   - Windows: `C:\Users\<用户名>\.workbuddy\skills\culture-event-sop\`
   - macOS/Linux: `~/.workbuddy/skills/culture-event-sop/`
3. 重启 WorkBuddy 或重新加载 skills，即可使用

### 方式二：手动复制

直接将本 Skill 的文件夹复制到上述路径即可。

## 三、使用场景

### 场景1：活动全流程规划（最常用）

**示例对话：**

```
用户：我要筹备一个员工大会
AI：你好！为了给你最精准的方案，先确认几个关键信息：
    1. 这次活动的背景是什么？（年度战略传达/组织架构调整/团队融合...）
    2. 有确定的活动时间吗？
    3. 活动是纯线下还是线上线下混合？预计多少人？

用户：组织架构调整，5月21日，混合，线上1000人线下500人
AI：再确认2个细节：GM参加吗？Dowson参加吗？预算区间？

用户：都参加，预算1万
AI：信息齐了！先给你方案框架预览...（展示框架）
    这个方向对吗？

用户：对的
AI：（输出完整方案）需要我生成 Word/Excel/HTML 文件吗？

用户：生成HTML
AI：（生成文件并提供下载）
```

### 场景2：环节细节查询

**示例输入：**
- "QA问卷怎么设计？"
- "什么是技术联调？"
- "腾讯会议超过300人怎么办？"
- "高管谈参怎么写？"

**输出：** 操作步骤 + 完成标准 + 常见坑点 + 参考资源链接

### 场景3：场景匹配推荐

**输出：** 场景分析 → 推荐2-3个活动类型 → 推荐理由 → 参考案例

### 场景4：工具资源查询

**示例输入：**
- "有什么团建小游戏？"

- "有没有抽奖工具？"
- "推荐几个暖场互动环节"

**输出：** 分类资源列表 + 使用说明 + 下载链接

### 场景5：案例沉淀

**示例输入：**
- "活动做完了，帮我写个案例沉淀"
- "生成案例模板"

**输出：** 标准8模块案例模板（可直接填入）

### 场景6：排期规划

**示例输入：**
- "帮我做年度文化活动排期"
- "下半年有什么文化活动建议？"

**输出：** 季度排期表 + 关键里程碑 + 建议活动类型

## 四、对话流程说明

这个 Skill 采用**对话式引导**，不是一次性输出大段方案，而是分轮次收集信息：

```
Round 1: 用户提问
    → AI判断信息是否足够
    → 不够：反问1-3个问题（提供选项）
    → 足够：进入Round 2

Round 2: 用户补充信息
    → AI继续判断
    → 还有缺失：继续追问（每次最多3个）
    → 信息完整：输出方案框架预览

Round 3: 用户确认方向
    → 输出完整方案
    → 询问是否需要生成文件
```

### 信息收集清单

| 优先级 | 信息项 | 说明 |
|--------|--------|------|
| P0 必须 | 活动类型 | 员工大会/leader offsite/团建/GM面对面/工作坊/Openday/下午茶围谈/表彰大会 |
| P0 必须 | 活动背景/目标 | 为什么做？希望达到什么效果？ |
| P1 重要 | 活动日期 | 有确定日期吗？还剩多久筹备？ |
| P1 重要 | 活动形式 | 纯线下/混合/纯线上？线上多少人？线下多少人？ |
| P1 重要 | 高管参与 | GM参加吗？Dowson参加吗？ |
| P1 重要 | 预算区间 | 高(≥200元/人)/中(100-200)/低(50-100)/无(<50)，或说"跳过" |
| P2 可选 | 特殊要求 | 必须包含或避开的环节？ |

## 五、输出格式

### 默认输出（对话中直接展示）

- Markdown 表格 + 结构化文本
- 包含：目标、时间线、checklist、案例、风险、资源链接

### 文件输出（用户明确要求时生成）

支持三种格式：

| 格式 | 适用场景 | 命令示例 |
|------|---------|---------|
| **Word** | 需要打印、审批、分发给团队 | "生成Word文档" |
| **Excel** | 需要团队协同编辑checklist | "生成Excel表格" |
| **HTML** | 需要在线查看、分享链接 | "生成HTML文件" |
| **全部** | 需要多种格式备用 | "生成所有格式" |

## 六、活动类型覆盖

| 活动类型 | 状态 | 说明 |
|----------|------|------|
| 员工大会 | ✅ 完整 | 含通用清单+员工大会专项补充 |
| leader offsite | ✅ 完整 | 含专项补充 |
| 团建 | ✅ 完整 | 含游戏推荐+团建专项补充 |
| GM面对面 | ✅ 完整 | 含高管参与专项补充 |
| Openday / 开放日 | ⚠️ 基于推断 | 暂无专项SOP，基于员工大会推断 |
| 工作坊 | ⚠️ 基于推断 | 暂无专项SOP |
| 下午茶围谈 | ⚠️ 基于推断 | 暂无专项SOP |
| 表彰大会 / 颁奖 | ⚠️ 基于推断 | 有暖场和颁奖片段，缺完整SOP |

> 标注"基于推断"的活动类型，方案会基于通用清单+场景推断生成，精准度不如有专项SOP的活动类型。后续补充专项SOP后可提升。

## 八、注意事项

1. **对话式引导**：不要期望一句话出完整方案，AI 会分2-3轮收集信息
2. **跳过机制**：预算等可选信息可以说"跳过"或"待定"
3. **内容标注**：基于原始Excel数据的内容会明确标注；基于通用经验推断的内容会标注"（经验推断）"
4. **对接人信息**：案例展示时隐藏文化对接人姓名，只展示部门和活动信息
5. **历史排期**：各部门历史排期仅在用户主动询问时提供
6. **定期更新**：`references/extracted_data.json` 需要定期同步 Excel 最新版本

## 十、长期使用建议

### 需要补充的材料（按优先级）

| 优先级 | 材料 | 补充后效果 |
|--------|------|-----------|
| 高 | Openday/工作坊/下午茶/表彰大会 专项SOP | 这些活动类型的方案精准度大幅提升 |

### 更新方式

1. 修改原始 Excel 文件
2. 重新运行数据提取脚本，更新 `extracted_data.json`
3. 如有新资源链接，更新 `resource_links.json`
4. 如有新活动类型SOP，新增对应的 prompt 文件

## 十一、常见问题

**Q：为什么AI不直接给我完整方案，还要问这么多问题？**
A：文化活动筹备涉及很多变量（人数、预算、高管、时间等），不同变量组合方案差异很大。先收集信息再出方案，避免给你一堆用不上的内容。

**Q：可以跳过信息收集直接出方案吗？**
A：可以。如果你把所有关键信息一次性告诉AI（活动类型+背景+日期+形式+人数+高管+预算），AI会直接出完整方案。

**Q：生成的文件在哪里找？**
A：文件会保存在当前工作空间的目录下，AI会告诉你具体路径。

**Q：有些链接打不开？**
A：微信文档/微盘链接需要对应权限才能访问。如果打不开，请联系文件所有者申请权限。

**Q：能不能增加新的活动类型？**
A：可以。补充该活动类型的SOP数据后，在 `prompts/` 下新增对应的 prompt 文件，并在 `SKILL.md` 中注册即可。
