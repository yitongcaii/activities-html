# 培训宣传文案生成器（ABCD 框架）

## Overview

把"培训 / 活动宣传简介"类文案的产出，固化成一套可直接套用的结构化提示词框架。
用户按 **A 动作 → B 背景 → C 约束 → D 期望输出** 四段填空，即可生成多版本、可投递的文案。
额外支持**学习模式**：把往期文案喂给本技能，自动总结风格规律并沉淀为「风格档案」，
之后同场景只需给活动关键信息，即可自动套用历史风格成稿。
也支持**转写模式**：直接粘贴会议转写 / 纪要，自动抽取其中的活动要素（主题、讲师、时间、地点、是否带电脑实操、受众与渠道线索），
回填到 ABCD 的 B/C/D 基线后再成稿——信息已在转写里的不重复问，只追问缺失项。

## 何时使用

- 用户说"帮我写一个 XX 活动的群公告 / 招募推文 / 海报文案 / 报名通知"。
- 用户要写讲座、沙龙、workshop、内训、训练营、公开课等宣传简介。
- 用户说"总结一下我之前的文案风格""以后按这个调性自动写"。
- 用户粘贴了若干篇往期宣传文案，并希望提炼规律复用。
- 用户粘贴会议转写 / 纪要 / 录音文字稿，并要求"根据转写写个宣传文案"。

## 核心框架：ABCD 四段填空

完整填空模板见 `references/abcd-template.md`（可直接复制发给用户填）。
字段含义与要点：

**A（动作 / Action）** — 要写什么类型的文案。
> 例：沙龙活动企微群公告 / 课程招募公众号推文 / 线下 workshop 海报文案 / 内训报名邮件。
> 作用：决定文案的体裁、信息密度、渠道语气基线。

**B（背景 / Background）** — 让文案"有根"的上下文。
- 你的角色身份（如 HRBP / 活动运营 / 部门接口人）
- 受众特征（岗位、性别比、地域、痛点、对哪些词免疫）
- 发布渠道（企微群 / 公众号 / 乐享 / 海报 / 邮件 / 朋友圈）
- 活动关键信息：主题、讲师/嘉宾、时间、地点或线上链接、是否需带电脑实操、名额/费用/前置要求等

**C（约束 / Constraints）** — 语气与红线。
- 语气风格（如"活泼网络化但礼貌得体、无歧义""专业克制""热血动员"）
- 字数上限（如 ≤200 字 / 不限）
- 禁用词（如 赋能、闭环、抓手、一站式）
- 开头是否需要钩子（抛痛点 / 设悬念 / 直接上价值）
- 其他禁忌（emoji 堆砌、感叹号过多、标题党）
- 礼貌与无歧义红线（默认开）：不用模糊时间（"今天/尽快"须给具体日期与明确时限）；不用轻浮或易误读表情（如 `[勾引]` 在正式/有领导的群慎用）；跨文案的人名、品牌名、时间须前后一致；零错别字。

**D（期望输出 / Desired Output）** — 成稿规格。
- **活动阶段（关键）**：预热 / 进行中 / 完成后，可多选。选"进行中"时需给定连发条数与各条时机（开场提醒 / 茶歇奖品 / 互动有奖）。同一活动往往需跨阶段产出序列，而非单篇。
- 生成版本数量（按阶段分别计，如 预热 2 版 / 进行中 4 条 / 完成后 1 版）
- 各版本侧重点（如 版本1 突出讲师吸引力；版本2 突出内容价值感；版本3 突出限时名额）
- 每版结尾是否带报名链接引导（全带 / 仅某版 / 不带）

## 工作流：四种模式

> ⚠️ **风格档案依赖说明**：模式 C / D 的"自动套用历史调性"前提是用户曾运行**模式 B** 并建立 `references/style-profile.md`。本技能**不凭空记忆**任何往期文案或用户风格——它没有任何内置数据库。未建立档案时：模式 C 退回模式 A 显式追问；模式 D 仅做转写要素抽取，语气按用户当场指定的 C 约束或通用默认，绝不伪造"你的风格"。所谓"自动"，只指自动抽取当轮输入（转写/活动事实），而非自动知晓历史。

### 模式 A — 直接生成（标准 ABCD）

1. 若用户未给全 ABCD，用 `references/abcd-template.md` 的精简版逐段追问；已给的字段不重复问。
2. 按 D 的版本数与侧重点，逐版生成，严格遵守 C 的约束（语气、字数、禁用词、钩子）。
3. 按下方「输出格式」渲染，每版独立成块，可直接复制投递。
4. 文末给一行「校验清单」回显本次实际遵循的约束（语气 / 字数 / 禁用词命中 / 钩子 / 报名引导），便于用户快速验收。

### 模式 B — 学习往期文案（沉淀风格档案）

触发：用户粘贴 ≥2 篇往期宣传文案，并提出"总结规律 / 学一下我的风格 / 以后按这个写"。

1. 逐篇拆析，提取风格维度（对齐 `references/style-profile-template.md` 的字段）：
   - 结构范式（是否先钩子后信息、信息排布顺序、是否分点）
   - 语气与高频口头禅（轻松 / 专业 / 热血；惯用连接词、收尾句式）
   - 钩子类型（痛点直击 / 悬念 / 数据 / 身份认同）
   - 禁用与偏爱词（反向归纳：他们爱用 vs 刻意避开）
   - 结尾引导方式（报名链接话术、CTA 样式）
   - 字数区间与渠道适配
2. 将归纳结果写成结构化「风格档案」，用 Write 工具**覆盖写入** `references/style-profile.md`。
3. 向用户回显一份「规律摘要表」（维度 → 结论 → 证据原文节选），并提示：下次同类需求会自动读取该档案。

### 模式 C — 套用风格档案自动生成

1. 生成前先 Read `references/style-profile.md`；若不存在，退回模式 A。
2. 用档案预填 B（受众/渠道基线）、C（语气/禁用词/钩子偏好，**默认遵守"礼貌得体、无歧义"红线**）、D（阶段序列 + 版本数与侧重点模板）。
   - 若 A 指示「英语角」，额外加载 `references/english-corner-template.md` 作为固定结构脚手架（预热 / 进行中 3 波 / 完成后），按其固定基线与占位直接展开，只追问占位项。
3. 只向用户追问：**A 文案类型** ＋ **本次活动的专属 B 事实**（主题/讲师/时间/地点/名额等变动项）＋ **目标阶段**（用户未指定时，默认按"预热→进行中→完成后"出全套序列）。
4. 生成时优先套用档案中的钩子套路、口头禅、结尾 CTA；仍逐版输出并附校验清单。
5. 若用户说"更新一下我的风格"，重新执行模式 B 覆盖档案。

### 模式 D — 从会议转写生成

触发：用户粘贴会议转写 / 纪要 / 录音文字稿，并要求据此写宣传文案。

1. 通读转写，抽取 B 的可获取事实：活动主题、讲师/嘉宾及亮眼标签、时间、地点或线上链接、是否提及带电脑实操、受众线索（谁在听、什么部门）、渠道暗示（提到发群/公众号）。
2. 若已沉淀 `references/style-profile.md`，同时读取并套用（同模式 C）。
3. 将抽取结果回填到 ABCD 的 B/C/D 基线；**只针对转写中缺失或歧义的项追问用户**（例如时间只说"下周"、地点未定、语气未指明），已能确定的不重复问。
4. 先向用户回显一张「转写要素提取表」（字段 → 提取结果 → 来源句），再按「输出格式」逐版成稿；文末校验清单注明"信息来源：会议转写 + 用户补充"。
5. 若转写本身已含完整信息，直接出稿，零追问。

## 输出格式（直接套用，无需额外说明）

每版文案按以下块输出，用户可整块复制：

```
【版本 N ｜ 侧重点：<xxx>】
<钩子句（若有）>
<正文>
<结尾报名引导（若 D 要求）：👉 报名链接：<填入链接或占位 [链接]>>
— 字数：约 XXX 字 ｜ 语气：<…> ｜ 钩子：<有/无> ｜ 禁用词命中：<无/列出>
```

校验清单（所有版本之后单列一行）：
`✅ 已遵循 — 语气:<…> ｜ 字数≤<上限> ｜ 禁用词:<未出现/已规避> ｜ 钩子:<有/无> ｜ 报名引导:<全带/仅版N/无>`

- `references/english-corner-template.md` — 英语角专用固定结构脚手架（预热/进行中3波/完成后+固定基线+占位清单），A=英语角 时模式 C 自动加载。

> 删除示例目录 `scripts/`、`assets/` 中无用文件；本技能无需脚本与素材。
