把下面整段发给用户填，或按其字段逐项追问。带 `*` 为必填，其余可留空走默认。

---

## 🅐 动作（要写什么文案）
- 文案类型*：________________（如：沙龙活动企微群公告 / 课程招募推文 / 线下 workshop 海报文案 / 内训报名邮件 / 讲座预告）
- 投递渠道*：________________（企微群 / 公众号 / 乐享 / 海报 / 邮件 / 朋友圈）

## 🅑 背景（让文案有根）
- 你的角色身份：________________（如 HRBP / 活动运营 / 部门接口人）
- 受众特征*：________________（岗位、性别比、地域、典型痛点、对哪些词免疫，如"技术男、外地多、反感'赋能'套话"）
- 活动主题*：________________
- 讲师 / 嘉宾*：________________（姓名+头衔+一句最亮眼的标签，如"张三｜十年架构师，主导过XX亿级系统"）
- 时间*：________________（日期+时段）
- 地点 / 线上链接*：________________
- 是否需带电脑实操：□ 是（请带笔记本） □ 否
- 其他关键信息：名额____ / 费用____ / 前置要求____ / 福利____

## 🅒 约束（语气与红线）
- 语气风格*：________________（如"活泼网络化但礼貌得体、无歧义" / "专业克制" / "热血动员"）
- 字数上限：________________（如 ≤200 字 / 不限）
- 禁用词：________________（如 赋能、闭环、抓手、一站式）
- 开头钩子：□ 要（痛点/悬念/数据） □ 不要
- 礼貌与无歧义红线（默认开）：不用模糊时间（"今天/尽快"→给具体日期与时限）；不用轻浮/易误读表情（[勾引]在正式群慎用）；跨文案人名/品牌/时间须一致；零错别字
- 其他禁忌：________________（如 不堆 emoji、不用过多感叹号、不标题党）

## 🅓 期望输出（成稿规格）
- 活动阶段*：□ 预热 □ 进行中（连发____条：开场提醒/茶歇奖品/互动有奖） □ 完成后（可多选）
- 生成版本数*：________________（按阶段分别计，如 预热2版 / 进行中4条 / 完成后1版）
- 各版侧重点*：
  - 版本1：________________（如 突出讲师吸引力）
  - 版本2：________________（如 突出内容价值感）
  - 版本3（可选）：________________
- 结尾报名引导：□ 每版都带 □ 仅某版（注明____） □ 都不带

## 精简追问版（用户嫌长时，逐条问，已给的不重复）

1. 写哪种文案、发哪？→ A
2. 谁看、讲啥主题、谁来讲、啥时候、在哪？→ B
3. 什么调性、限多少字、别用哪些词、开头要不要钩子？→ C
4. 哪个阶段（预热/进行中/完成后）、要几版、各突出啥、结尾给不给报名链接？→ D
