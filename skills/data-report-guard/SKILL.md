# data-report-guard · 防错出报告

## 目标
出一份**每个核心数字都可溯源、计算口径白纸黑字、假设全暴露、未知值不编造**的数据报告。在出数前卡死「源错 / 算错 / 口径换 / 编」四大雷区。

## 触发判断（代理怎么判）
- **激活**：用户原话含「防错 / 按模板 / 出报告要防错 / 做数据分析(防错)」且任务是出数据/报告 → 走下方流程。
- **不激活**：仅说「出个报告」「做个分析」无「防错」字样 → 按普通任务处理。
- **不激活**：只问「这个数对吗」「某某活动来了几人」 → 这是核查不是出报告。
- 激活后**未指定源文件** → 必须反问精确路径 + sheet，禁止自己找 / 用旧文件。

## 执行流程（6 步：动作 → 调用工具 → 产出）

| 步 | 代理动作 | 调用工具 | 产出 |
|---|---|---|---|
| **1 锁源** | 确认用户指定的精确文件路径 + sheet；未指定则停下反问 | `Glob` / `Read` 验证文件存在、读指定 sheet | 锁定源清单（路径+sheet+行列范围） |
| **2 写死口径** | 把计算规则逐条写成白纸黑字（去重键 / 剔除规则 / 人均公式等） | 无（纯撰写） | 口径清单（bullet） |
| **3 复述确认** | 用一句话复述「源+口径」，**停住等用户点头**再算 | 无（等待） | 用户确认信号 |
| **4 埋基准数** | 若用户给了 100% 确定的数，先单独算它、对上再继续 | `Read` + `Bash`(python) 或 `xlsx` 重算 | 基准数校验通过 / 不通过 |
| **5 内嵌溯源 + 占位** | 每个核心数字后标来源行号；未知值写 `__` / `【待补】`，**绝不估算** | `Write`(md / html) | 带溯源标注 + 占位的报告草稿 |
| **6 出报告** | 组装最终报告（数据段 + 口径段 + 假设段 + 自查段） | `Write` | 成品报告 |

## 边界（不做什么）
- ❌ 不自动触发（无「防错」字样不跑）
- ❌ 不替用户填估算值（未知一律占位）
- ❌ 不改源数据文件
- ❌ 不主动推 GitHub Pages / 不发企微（除非本轮回话另行授权）
- ❌ 源文件找不到时不硬编，必须反问
- ❌ 单次只服务一个报告任务，不并行多份

## 结果验证（自查机制）
报告产出后代理**强制跑自查**，文末输出：
1. 每个核心数字 → 来自哪个源文件哪一行（答不出 = 不可信）
2. 计算口径逐条复述
3. **标出 3 个最没把握、建议用户手算复核的数字**
4. 断言：本报告无 `__` 被自动填充、口径段存在

可选交叉验：用 `Bash` + python 对抽样指标重算，与报告值比对，不符则标红。

可直接复制使用的自查话术（代理对用户说）：
> 这是报告。逐条说明：① 每个核心数字来自哪个源文件哪一行；② 计算口径；③ 标出 3 个我最没把握、建议手算复核的数字。

## 最终交付物
一份报告，含 4 段：
- **数据段**：每个数带溯源标注
- **口径段**：白纸黑字的规则
- **假设段**：本次所有假设（抓偷偷脑补）
- **自查段**：3 个待手算复核数 + 无编造断言

格式默认 md；若用户要展示型，复用已上线的 Bento 卡片墙逻辑（不在此 skill 内打包 HTML 资产）。

## 防错指令模板（可直接套用）
做之前先做到这 6 条：
① 只使用我指定的文件 **__** 的 sheet **__**，不准用其他来源；
② 严格按口径：**__**（逐条写）；
③ 先用你自己的话复述一遍口径，等我确认再动手；
④ 报告里每个核心数字后标注来源行号；
⑤ 凡是我没给真实值的数字，用 `__` 占位，**不许估算填写**；
⑥ 最后单独列一段"本次我做了哪些假设"，供我核对。
