# 输入数据结构与字段同义词（schema.md）

本文件定义 `scripts/normalize.py` 接受的输入形状、标准字段与中文字段同义词、阶段识别规则。
WorkBuddy 在 Step 1 把用户的原始数据喂给 normalize.py 前，可先据此预判字段能否被识别。

## 一、支持的输入文件

| 格式 | 扩展名 | 备注 |
|------|--------|------|
| CSV | `.csv` | 默认；首行为表头，UTF-8（含 BOM 亦可） |
| Markdown | `.md` / `.markdown` | 取第一个管道表格（`| a | b |` 形式） |
| Excel | `.xlsx` / `.xls` | 需 `openpyxl`：`pip install openpyxl`；否则请另存为 CSV |

## 二、三种输入形状（任选其一）

1. **单文件 + 阶段列**：一个表含「阶段」列（值含 前/中/后 或 pre/during/post），或含日期列 + `--period-start/end`。
2. **单文件 + 日期列**：用 `--date-col` 指定日期列，脚本按时间段切分前/中/后。
3. **三文件分离**：`--pre` / `--during` / `--post` 各传一个文件（最不易歧义，推荐）。

> 渠道明细单独用 `--channels` 传入（含「渠道/来源」列 + GMV/成本/拉新/曝光）。

## 三、标准字段与中文字段同义词

### 计数 / 金额类（多行聚合时求和）

| 标准字段 | 含义 | 同义词（含中英文） |
|----------|------|--------------------|
| `gmv` | 成交额 / 销售额 | GMV, 成交额, 销售额, 营收, sales, revenue |
| `cost` | 成本 / 花费 | cost, 成本, 花费, 投入, 总费用, 费用, spend, budget |
| `new_users` | 新增用户 / 拉新数 | new_users, 新增用户, 拉新数, 拉新, 新客数, 新增会员, 获客数, 新用户 |
| `impressions` | 曝光 / 展示 | impressions, 曝光, 曝光量, 展示量 |
| `reach` | 触达人数 | reach, 触达, 触达人数, 覆盖人数, 覆盖 |
| `mentions` | 声量 / 提及 | mentions, 声量, 提及, 讨论量, buzz |
| `shares` | 转发 / 分享 | shares, 转发, 分享 |
| `orders` | 订单数 | orders, 订单, 订单数 |
| `members` | 会员数 | members, 会员, 会员数 |
| `users` | 用户 / 活跃 / 参与 | users, 用户数, 活跃用户, 参与人数 |

### 比率类（多行聚合时取均值）

| 标准字段 | 含义 | 同义词 |
|----------|------|--------|
| `repurchase_rate` | 复购率（存为小数 0.25=25%） | repurchase_rate, 复购率, 复购, 回购率 |

### 可直填或推导

| 标准字段 | 含义 | 同义词 | 推导规则 |
|----------|------|--------|----------|
| `acquisition_cost` | 拉新成本 CAC | acquisition_cost, 拉新成本, 获客成本, cac | 缺失时用 `cost / new_users` 推导 |

## 四、阶段识别优先级

1. 显式阶段列（`--phase-col` 或自动识别「阶段/时期/环节/周期/分期/phase」列）→ 按值匹配 前/中/后。
2. 日期列 + `--period-start/end` → 早于起点=前，区间内=中，晚于终点=后。
3. 启发式兜底：无法判定时归入「活动中」并告警，需用户确认。

## 五、脱敏与剔除（铁律）

解析时若列名命中以下模式，**整列剔除且不落盘**：
手机号/电话/身份证/Token/密钥/secret/密码/api_key/姓名/员工/负责人。
数值中若混入手机号（11 位 1 开头），由下游报告统一脱敏展示。
