# 治愈系插画师 · healing-illustrator

> 治愈系水彩插图 · 生图 Prompt 模板

## 一、Prompt 三段式架构

我们把一个好的 Prompt 拆成 **3 个段落 × 各司其职**：

```
┌────────────────────────────────────────────────────────────┐
│  第 1 段 · 氛围锚定  →  我要什么样的"壳"（画风+背景+配色）     │
│  第 2 段 · 内容描述  →  画面里要装什么"瓤"（主体+元素+文字）   │
│  第 3 段 · 负向控制  →  我绝对不要什么（避雷+锁定+硬约束）     │
└────────────────────────────────────────────────────────────┘
```

三段顺序不能乱，因为生图模型是**从前往后读**的：先建立调性，再填充内容，最后用负向约束兜底。

## 二、三段式骨架模板（直接复制套用）

```
【第1段 · 氛围锚定】

几米（Jimmy Liao）绘本风格的手绘水彩插画。
暖米黄底色（#F4ECDC）带轻微水彩晕染纹理，画面上方角落点缀几朵柔软白云。
成年人比例，身材瘦长柔和，不要大头娃娃、不要萌系二次元。
细铅笔草稿线条 + 柔和水彩上色，整体安静诗意、略带忧郁的温暖感。
配色严格锁定：暖米黄(#F4ECDC)、薄荷绿(#A8D5BA)、桃橙(#F5B095)、
天空蓝(#A8C8E8)、金棕(#C08A2A)、熔岩金(#E8A53A)、柔白。
所有中文文字使用金棕色手写字体，清晰可辨。


【第2段 · 内容描述】  ← ★★★ 每张图唯一需要改写的地方 ★★★

[在这里描述：
 · 画面中心是什么
 · 四周围绕哪些元素
 · 人物（如有）：姿态、服饰、表情
 · 每个元素上的文字标签具体是什么（用引号写清楚）
 · 元素之间的空间关系（左/右/上/下/连线）
 · 底部是否需要 banner 标语]


【第3段 · 负向控制】

绝对不能出现的要素：
1. 大头娃娃、Q 版萌系、日漫大眼睛、3D 渲染感、写实人像
2. 画面过满、背景花哨、彩色晕染过于鲜艳
3. [具体场景约束，比如："图中必须恰好 3 个文件夹，不能是 4 个"]
4. [文字约束，比如："底部标语必须原样是：XXXX，不能改动"]
5. [元素约束，比如："每个工具的指向线必须指向岛屿的不同区域"]
```

## 三、六色配色锁（系列一致性的命脉）

做一个系列的多张图，**必须用同一套颜色**，否则前后割裂。这 6 个色号建议保存为色板：

| 色名 | HEX | 含义定位 |
|---|---|---|
| 暖米黄 | `#F4ECDC` | 全局底色 |
| 薄荷绿 | `#A8D5BA` | Insight 观测类 / 团队看板 |
| 桃橙 | `#F5B095` | Assistant 互动类 / 对话机器人 |
| 天空蓝 | `#A8C8E8` | Generator 生产类 / 文档工具 |
| 金棕 | `#C08A2A` | 标题 / 手写文字 / 标签底 |
| 熔岩金 | `#E8A53A` | 核心隐喻（底层能量带 / 产品第一性） |

## 六、一句话心法

> **几米风的灵魂 = 暖米黄底 × 成人比例侧视 × 克制水彩晕染 × 金棕手写中文 × 拒绝萌系。**
>
> 把这五个关键词钉死在第 1 段，6 个 HEX 色号钉死在配色锁里，
> 第 2 段专心讲故事，第 3 段专心避雷。
>
> 其余的事，交给模型就好。
