# 高管谈参模板（draft_talking_points）

> 用途：为 Dowson / Wang / GM / 线负责人 生成「发言要点建议」。谈参 ≠ 逐字稿，是给高管看的"该讲什么、不该讲什么、怎么答"。

## 输入变量
- 发言人：{{executive}}（Dowson / Wang / GM / 线负责人）
- 场合：{{occasion}}
- 目标：{{goal}}（取自 references.audience_goals）
- 已知要点 / 老板分工：{{known_points}}

## 输出结构
### 1. 核心信息（必讲）
- 战略定调：____（结合部门阶段目标）
- 对员工的肯定：____（情感链接 / 鼓舞士气）
- 关键战役 / 里程碑：____
- Call to action：____

### 2. 按目标分层展开
> 依据 references.audience_goals，针对本场观众选 2-3 个目标展开：
- 员工视角：稳定军心 / 战略传达 / 力出一孔
- GM 视角：了解一线心声 / 决策穿透力
- 部门视角：战略解码 / 组织韧性 / 打破部门壁垒

### 3. QA 预案（对齐老板分工）
> 来源：references.prep_sop.QA收集（提前 ≥1 周回收，对齐问答建议&老板分工）
- 可能问题 1：____ → 建议由 {{owner}} 回答，口径：____
- 可能问题 2：____ → ____

### 4. 禁忌 / 红线（需确认）
- 不提及：____（合规 / 保密）
- 数据口径：以最新官方为准（需确认）

### 5. 职位与署名（需确认）
> 来源：references.executives.Dowson.raw_title_block
- 本版暂用：{{suggested_title}}
- ⚠️（需确认）最终职位描述以高管秘书确认为准，参考：高管照片环节提前与秘书对齐。

## 标注要求
- 属于 SOP 的标（原始数据），推断的标（经验推断），待补的标（需确认）。
- 末尾附「需确认清单」：职位描述 / 老板分工 / 保密口径 / 本人确认。
