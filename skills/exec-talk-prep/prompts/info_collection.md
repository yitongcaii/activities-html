# 信息收集反问清单（info_collection）

> 用途：在产出任何谈参 / 致辞 / 主持稿之前，先澄清关键信息。每次最多问 3 个，给选项。

## 必收字段（按优先级）
- **P0**
  - 场合类型：员工大会 / Leader offsite / 颁奖 / 团建 / 其他（选一）
  - 发言人：Dowson / Wang / 部门 GM / 线负责人 / 基干 / 员工代表（可多选）
  - 核心目标：从 references.audience_goals 里选（稳定军心 / 鼓舞士气 / 战略传达 / 情感链接 / 文化校准 / 了解一线心声 / 战略解码 …）
- **P1**
  - 时长：__ 分钟
  - 风格：正式 / 轻松活泼 / 激励向
  - 形式：纯线下 / 线下+线上（腾讯会议 Webinar）/ 多地连线
  - 是否含互动环节：有 / 无（影响主持稿互动导入段）
- **P2**
  - 是否需要高管照片 & 职位描述确认：（需确认，默认要）
  - 保密等级：内部 / 保密（影响纪律提醒强度）

## 反问示例（每次挑 ≤3）
1. 「这次是员工大会还是 offsite？发言人里有 Dowson / Wang / GM 哪几位？」
2. 「致辞大概几分钟？风格偏正式还是轻松？」
3. 「线上参会人数会超 300 吗？要不要走 Webinar + 扩容？」
4. 「高管职位描述这版我先按「腾讯集团高级执行副总裁 / 云与智慧产业事业群 CEO / 汤道生（Dowson）」写，最终以秘书确认为准，可以吗？」

## 关键校验（输出前必须做）
- 预算/规模不匹配时提示（本 skill 不涉及，但如牵扯场地/礼品，提示参考 culture-event-sop）
- 若线上人数 > 300，提示扩容风险（见 culture-event-sop）
- 职位描述 / 谈参口径若用户未确认，明确标（需确认）
