🛑 绩效避坑清单

来源：《人力资源管理的深度思考》第 6 章「绩效真的有效吗？」(3649 字) + 你的绩效 / 新人答辩自动化场景
用法：每条 = 书中原话(论据) + 坑在哪 + 给你(做产品化/答辩时的落点)。标注案例出处，拒绝空话。
逐句精读8 大坑案例标注关联你的绩效

1坑：把绩效当"激发活力"的万能药

书中："我们做绩效的初衷是激发组织活力，但大部分企业的绩效最终成了发展的桎梏。"
案例："绩效毁了索尼"——很多日企反思绩效是否赋能了组织。"优秀的人不需要绩效管理，做与不做绩效，优秀的人就在那，拖后腿的也在那。"

坑在哪：对绩效期望过高，以为它能解决组织能力问题。

给你：做新人答辩/绩效流程时，先想清"激发还是控制"。流程是度量工具不是发动机，别让自动化答辩变成新的桎梏。

期望管理索尼案例
📌 出处：第6章 开头段 + "绩效毁了索尼"段

2坑：精力错配，死磕个人绩效

书中："我个人认为没有必要花精力去管理(个人绩效)，只要控制好强制分布，剩下的就交给业务部门。人力资源如果管到个人绩效了，可能是精力分配的失衡，捡了芝麻丢了西瓜。"

坑在哪：HR 投入太多在个人绩效，忽略组织绩效互锁（这才是战略解码的主线）。

给你：答辩自动化优先做组织/团队层的强关联与互锁，个人评价交给业务+强制分布即可，别把系统做成"管到每个人"。

组织绩效优先强制分布
📌 出处：第6章 "个人绩效真的那么重要吗" 段

3坑：目标拍脑袋 → 全员自嗨

书中："我们应当基于增量来定目标，否则拍脑袋的目标永远是空中楼阁，纯粹是一场自嗨。"组织绩效目标要"相对合理，否则个人绩效一片哀嚎"。

坑在哪：目标非增量导向，定太高人人完不成、定太低没挑战。

给你：答辩/目标设定模块加增量基线校验（同比/环比/行业），目标值不合理的，系统给红牌预警而不是照单全收。

增量定目标红牌预警
📌 出处：第6章 "个人绩效究竟为什么服务" 段

4坑：固浮比拍错 → 没激励 / 谈 offer 吃力

书中："浮动比例太低，没有激励性；浮动比例过高……可能我们谈 offer 都会吃力。合理的固浮比，是我们做薪酬设计的根本。"

坑在哪：浮动比例与岗位业绩强度不匹配。

给你：绩效和薪酬策略必须联动设计（第6章第3点）。做答辩看板时把"固浮比"作为校验维度，而非只算分。

固浮比薪酬联动
📌 出处：第6章 "我们的薪酬策略是否严谨" 段

5坑：组织绩效目标值不合理 → 捧杀 or 错杀

书中：组织绩效决定个体等级名额分布（见下表）。"这样就对组织绩效目标值设定的合理性提出很高要求，否则要么捧杀了大家，要么错杀了大家。"
组织等级SABCD
S30%40%30%--
A20%30%50%--
B10%20%70%--
C-20%70%10%-
D-10%60%20%10%

给你：答辩结果应用这套分布逻辑时，先审组织目标合理性再套比例，避免"组织差→全员背低绩效"的错杀。

强制分布目标合理性
📌 出处：第6章 组织绩效 "名额分布表" 段

6坑：绩效只用来算工资 → ROI 太低

书中："如果绩效只是用来算出一个绩效工资，那确实 ROI 有点太低了。"应和任职资格、晋升、人才盘点、评优、股权、裁员等强绑定，形成逻辑闭环。

坑在哪：绩效结果孤岛，不反哺其他模块。

给你：答辩自动化别只产出"分数"，要能一键回流到人才盘点/晋升/评优，让业务真重视。

结果应用逻辑闭环
📌 出处：第6章 个人绩效 结尾段

7坑：只考核不复盘 → 流于形式

书中："绩效管理和干部管理深度地、动态地联动。"红黄绿灯机制：连续两季度红灯负责人受质询，连续三季度红灯离开管理岗。"大家都用数据说话，达不成指标的就换个管理干部。"

坑在哪：考完即止，不复盘根因、不与干部管理挂钩。

给你：答辩/绩效系统加复盘会议机制+红黄绿灯，把"未达成指标"掰开揉碎，做成干部抓手而非打分机器。

绩效复盘红黄绿灯干部联动
📌 出处：第6章 组织绩效复盘段

8坑：盲目抄模板，不顾企业阶段

书中："管理没有对错，无非是一种选择。"MBO 还是 PBC、强/弱关联、激励/管控导向、产品线/职能线考核——都要看企业阶段：求规模还是利润、做大做强还是小而美。

坑在哪：别人家好用的，照搬就翻车。

给你：做流程产品化前，先让你的方案暴露假设（适用哪类团队/阶段），别做成"一套模板通吃"。

管理是选择审时度势
📌 出处：第6章 结尾"给老板的建议"段

🔍 第6章 关键句逐句精读（带出处）

  • "绩效承接了目标，还决定了浮动收入" → 点明绩效两大锚点：战略解码 + 薪酬绑定。做系统别漏任一个。（开头段）
  • "HR 的视角永远在搞平衡，既想激发又怕失控" → 作者自剖绩效失效根因：保守。启发：产品化时给业务"可调参数"而非死规则。（为何失效段）
  • "组织绩效分解到位，才能做到销售渠道与产品互锁、业绩与资源互锁" → 互锁是组织绩效的灵魂，非考核。（构建体系第1点）
  • "组织绩效主要目的不在考核，而是确保目标一致性及结果互锁" → 推翻"绩效=打分"直觉，呼应坑2。（组织绩效段）
  • "TL 个人绩效 = 上级组织绩效×30% + 主管部门组织绩效×60% + 述职/360" → 管理者绩效公式范例，可抄进答辩模板。（个人绩效段）

🔧 用到的思维模型

  • 第一性原理：回到"绩效为何存在"——承接战略+决定收入，而非"别人都做所以我做"。
  • 奥卡姆剃剃刀：个人绩效"只控强制分布即可"，别过度设计；系统解决 80% 问题。
  • 预判质疑：作者主动认"管理无对错只是选择""目标可能自嗨"，先讲代价再给方案，诚实可信。
  • 系统互锁思维：组织绩效互锁（销产/业绩资源/前后台）是设计核心，不是打分层。
