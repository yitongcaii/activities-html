✓ 已完成 前端外链全部本地化（font-awesome / html2canvas / 企微 JS-SDK 已进 public/vendor），禁出网也能完整运行；CSP 已收紧为同源。

两种部署形态对比

A. Docker 容器 有容器平台选这个

适用

  • 内网有 TKEx / STKE / 公司 K8s / 蓝盾镜像部署

优点

  • 环境锁版本（node:20-alpine）
  • 进程自愈（restart 策略）
  • uploads 卷持久化清晰、换环境零配置

代价

  • 多一层镜像构建 / 推送

文件

  • Dockerfile
  • docker-compose.yml（node + mongo + uploads 卷）
  • .dockerignore

启动

docker compose up -d

B. 裸 VM + pm2 环境简单选这个

适用

  • 一台虚拟机，团队不熟容器

优点

  • 不用镜像构建，装依赖即跑
  • 排查直接（看进程 / 日志）

代价

  • 手动装 Node + 守护 + 开机自启

文件

  • deploy/start.sh
  • deploy/ecosystem.config.js

启动

bash deploy/start.sh → pm2 startup 开机自启

三条红线（不处理就不能用）

① CDN 本地化 已完成

  • font-awesome / html2canvas / 企微 JS-SDK 已进 public/vendor
  • index.html / tab-calendar.js 引用已改本地
  • server.js CSP 已收紧为同源
  • 知识库导出字体：EXPORT_USE_GOOGLE_FONTS=false 降级系统字体（要美观设 true）

② OA 网关身份头 需联调

  • 身份 100% 靠网关注入 x-staff-*
  • 没有它 → 所有用户身份为 null，日历编辑 / 开课 / 拉群按钮全不显示
  • 本地预览可用 x-staff-override 头，生产必须真网关
  • 需和网关联调：请求头字段名 + 透传到 /api/*

③ 外网能力降级 需确认

  • 混元 API（AI 助手）：无 key / 不可达 → 仅该功能失效，不崩
  • iWiki MCP（知识库同步）：不可达 → 仅同步失败，核心正常
  • 两项都走 try/catch，失败不影响日历 / 提交 / 海报 / 拉群
随时切换 / 上线步骤

选 Docker

  • 复制 .env.production → .env，填 BASE_URL / HUNYUAN_API_KEY
  • docker compose up -d
  • 确认：curl localhost:8080/api/me 返回身份（需网关带头）
  • OA 网关反代到容器端口 8080，注入身份头

选裸 VM

  • 装 Node 20 + MongoDB（或指向内网 Mongo）
  • 放 .env，bash deploy/start.sh
  • pm2 startup 设开机自启；pm2 logs 看日志
  • OA 网关反代到 8080，注入身份头
