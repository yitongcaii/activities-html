一键脚本

Ollama + Open WebUI

私人 ChatGPT · 免费 + 隐私

本地跑大模型（DeepSeek / Qwen / GLM…），数据不出本机。Open WebUI 是类 ChatGPT 的网页界面。

  1. 双击 setup-ollama-openwebui.bat
  2. 自动装 Ollama → 拉 qwen2.5:7b → 起 WebUI
  3. 浏览器开 http://localhost:8080 注册即用
打开部署脚本
# 手工最小命令 winget install Ollama.Ollama ollama pull qwen2.5:7b pip install open-webui && open-webui serve
📖 能干啥 · 怎么用

有什么用

  • 写东西：沙龙文案、PPT 大纲、周报、邮件 —— 公司文档不传外部服务器，隐私归你
  • 写代码：帮你写 / 改 Python、批量处理表格
  • 翻译润色：中英互译、把口语改成正式稿
  • 问答 / 头脑风暴："团建方案怎么设计""活动 SOP 怎么写"，可连续追问
  • AI 沙龙 Demo：现场给大家看"本地大模型长啥样"，离线可演示

怎么用（装完后）

  1. 浏览器开 http://localhost:8080（脚本跑完通常会自动弹）
  2. 首次注册：填任意邮箱（如 a@b.com）+ 密码 → 本地账号，不联网不发邮件
  3. 进首页，右上角模型选 qwen2.5:7b（中文最好）
  4. 直接打字聊天，跟用 ChatGPT 一模一样

日常开关

  • 每次要用：双击脚本 → 等它开新窗口 → 开 8080（Ollama 装完会自动后台运行，多数情况直接开网页就行）
  • 关机：直接关电脑；Ollama 后台自启
  • 卡了打不开：重新双击脚本一次

⚠️ 模型 qwen2.5:7b 占 ~4.5GB，首次回复会慢几秒（本地加载），不是坏了。

一键脚本

ComfyUI

本地 AI 画图 / 视频

节点式 Stable Diffusion 前端，最主流的出图/出视频工作流。推荐 NVIDIA 显卡。

  1. 双击 setup-comfyui.bat
  2. 克隆 + 装 CUDA 版 PyTorch + 依赖
  3. 浏览器开 http://localhost:8188
打开部署脚本
# 无 N 卡也能跑（CPU，较慢） pip install torch torchvision pip install -r requirements.txt python main.py
📖 能干啥 · 怎么用

有什么用

  • 出图：活动海报、头像、插画、概念图
  • 出视频：短视频素材、动态背景
  • 可控生成：节点式工作流，精确到每一步参数

怎么用（装完后）

  1. 浏览器开 http://localhost:8188
  2. 左侧拖节点搭工作流，或加载现成工作流 JSON
  3. 在"CLIP Text Encode"节点填提示词（英文效果更好）→ 点"Queue Prompt"生成
  4. 右侧看结果，右键保存

日常开关

  • 起服务：双击脚本（会自动开 8188）
  • 关机：直接关；下次双击重启
  • 无 N 卡：脚本会自动走 CPU 版，出图慢但能跑
一键脚本

Langflow

拖拽搭 Agent · 零代码

可视化拖拽编排 RAG / Agent / 工作流。沙箱环境无法托管，本机双击脚本即可起服务（进去填个 LLM API Key 就能玩）。

  1. 双击 setup-langflow.bat
  2. 自动建环境 + 装 Langflow + 起服务
  3. 浏览器开 http://localhost:7860，设置里填 Key
打开部署脚本
# 起好后手动重启 lfenv\Scripts\activate langflow run
📖 能干啥 · 怎么用

有什么用

  • 不写代码搭 Agent：拖节点连线就能组一个会调用工具 / 知识库的 AI
  • RAG 问答：导入文档做本地知识库问答
  • 工作流原型：快速验证一个 AI 流程再决定要不要开发

怎么用（装完后）

  1. 浏览器开 http://localhost:7860
  2. 从模板选一个（如"Basic Prompting"或"Chatbot"）
  3. 点设置 → 填 LLM API Key（DeepSeek / 通义 / OpenAI 都行）
  4. 拖节点连起来 → 点播放跑通

日常开关

  • 起服务：双击脚本（自动开 7860）
  • 重启：激活环境后 langflow run

⚠️ 需要至少一个 LLM API Key 才能跑通（云端模型，按量计费）。

一键脚本

Dify

企业级 AI 平台 · 自托管

不写代码搭 RAG + Agent + 工作流，带知识库与可视化编排。需先装 Docker。

  1. 双击 setup-dify.bat（会先装 Docker）
  2. 启动 Docker 就绪后按任意键继续
  3. 浏览器开 http://localhost 注册即用
打开部署脚本
# 前置：Docker Desktop 已启动 git clone https://github.com/langgenius/dify.git cd dify/docker && docker compose up -d
📖 能干啥 · 怎么用

有什么用

  • 知识库问答：导入公司文档 / 活动 SOP，做成可对话的知识助手
  • 可视化 Agent / 工作流：不写代码搭复杂 AI 流程
  • 对外发布：可生成 Web App / API 给团队用

怎么用（装完后）

  1. 确保 Docker Desktop 已启动（托盘有鲸鱼图标）
  2. 浏览器开 http://localhost → 注册管理员账号
  3. 左侧"知识库"导入文档 → 建"应用"选 Chatbot / 工作流
  4. 绑定知识库 → 发布 → 对话测试

日常开关

  • 启动：Docker 打开 → 进 dify/docker 目录 docker compose up -d
  • 停止：docker compose down

⚠️ 必须先装 Docker Desktop，否则脚本会停在"请先启动 Docker"。
