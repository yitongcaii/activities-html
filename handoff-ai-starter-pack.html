4卡点 & 解决方案（核心）

6 个坑，每个讲清：现象 → 真凶 → 怎么解。新会话遇到同类报错直接对照。
#症状真凶解决方案
1双击 .bat「1 秒就没」SmartScreen/杀软 拦双击启动 .bat（连 pause 都来不及弹），非脚本逻辑错主推 cmd 手动跑：Win→搜索 cmd→cd 脚本目录→运行 .bat。服务类窗口不自动关
2cmd 内中文 echo 变 '韓韓滄僧...'GBK 编码：cmd 默认 GBK，非 ASCII 字符解析失败脚本首行 chcp 65001 >nul + 把中文 echo 全改英文
3cmd 报 was unexpected at this timeLF 换行：Write 工具默认产 LF，cmd 只认 CRLF，把下一行当续行拼崩 if 块Python data.replace(b'\n', b'\r\n') 全转 CRLF；写 bat 后必校验 CR==LF 行数
4Ollama 装不上 / winget 找不到Administrator 身份：误用管理员跑 cmd，WindowsApps 下无 winget必须普通 v_yitcai 身份；脚本开头 if not "%USERNAME%"=="v_yitcai" goto :err 护栏
5winget 仍装不好WindowsApps stub：双击命中商店 python/Ollama stub，不真运行不依赖 winget；curl 官方 installer 静默 --scope user 装；硬编码真实 python 路径
6Open-webui.exe serve 报 WinError 4551AppLocker 拦工作目录下 venv 的 torch.dll（非信任路径）venv 挪 %LOCALAPPDATA%\ollama-webui-venv + pip uninstall -y torch torchaudio torchvision
坑 3 详解 · LF-only 是隐形杀手已闭环

Write 工具在 Windows 上默认写 LF 换行。cmd.exe 把 LF 当成「续行符 \」，下一行被拼到上一行尾，if(...) 块结构直接崩，报 was unexpected at this time。诊断脚本（纯信息、语法绝对正确）也爆同样的错，就能反推是文件换行问题而非逻辑。

修复：写完 bat 立刻用一行 Python 转 CRLF，并比对 CR 行数 == LF 行数（如 87:87）确认转干净。

坑 6 详解 · AppLocker 拦 torch.dll已闭环

open-webui 通过 pip 默认拉 torch 作 optional audio 依赖（你用不到语音），但其 DLL 在工作目录 C:\Users\v_yitcai\WorkBuddy\... 下，不在 AppLocker 信任白名单 → 进程秒退。

修复组合：① venv 从 %~dp0venv-ollama 改 %LOCALAPPDATA%\ollama-webui-venv（LOCALAPPDATA 默认在信任路径）；② installer 也放 %LOCALAPPDATA%；③ pip install "open-webui>=0.6"（0.6 起 torch 非硬依赖）+ 装完立即 pip uninstall -y torch torchaudio torchvision 主动剔除。

收官坑 · 服务「看起来 refused」其实是过去时已闭环

用户 10:40 截图 localhost refused，但 open-webui 实际 10:42:59 才启动（晚 2 分钟）——截图是过去时。脚本末尾只 press any key 没等服务 ready，用户 100% 误以为挂了。

修复：① 末尾 start "Open WebUI" /B cmd /c "...serve --host 0.0.0.0 --port 8080" 真后台 + bind 0.0.0.0；② 加 wait-for-port 循环（每 3s curl 127.0.0.1:8080，最长 90s），通了才提示用户。

5踩过的坑 · 别再踩（铁律清单）

给新会话的「再犯必死」清单。任何一条违反都会重现「秒退 / 4551 / 乱码」。

🚫 写 Windows .bat 的 5 条铁律

  1. 强制 CRLF：写完用 Python replace(b'\n',b'\r\n') 转，并校验 CR==LF 行数。Write 工具默认 LF，cmd 不认。
  2. 首行 chcp 65001 >nul：否则任何中文/非 ASCII 被 GBK 解析成乱码命令。
  3. 硬编码真实 python 路径：避开 WindowsApps\python.exe 商店 stub（它不真运行）。
  4. 身份护栏：if not "%USERNAME%"=="v_yitcai" goto :err，拒绝 Administrator（其名下无 winget）。
  5. 全程 errorlevel + pause 兜底；服务脚本末尾必须 wait-for-port，别只 press any key。

🚫 公司机器装 Python 大依赖包铁律

  1. venv 必放 %LOCALAPPDATA%\%app%-venv，绝不放工作目录 / D 盘根（AppLocker 拦 DLL）。
  2. 主动卸非必需依赖：open-webui / ComfyUI 等纯 Web 工具 pip uninstall -y torch torchaudio torchvision。
  3. 钉版本：pip install "open-webui>=0.6"，避免镜像回退老版本拉 torch。
  4. TEMP 安装包也别放工作目录，用 %LOCALAPPDATA%。
  5. 仍报 WinError 4551 → 那是 LOCALAPPDATA 也不在白名单，需 IT 加白名单，不是脚本问题。

🚫 GitHub / Pages 铁律

  1. 文件名必须 ASCII：中文名 Pages 一律 404。
  2. 根目录放 .nojekyll。
  3. 每个 HTML 页脚统一：📌 本页由 yitong 沉淀整理 · 文化活动知识库。
  4. 推送走 SSH（yitongcaii 账号，key C:\Users\v_yitcai\.ssh\id_ed25519），不碰 PAT。
  5. git 用 git add <具体文件>，不用 -A（避免误带工作区遗留大文件）。

🚫 协作 / 交付铁律

  1. 企微禁发：绝不主动发企微消息，凌驾一切（除非用户本句明确授权）。
  2. 成品尽量给 HTML：单文件自包含、活泼卡片墙风；交付必给可点击链接（Pages 或 present_files 预览）。
  3. 每个 HTML 自动沉淀 Obsidian：写 .md（非拷 HTML）到 vault，嵌入访问链接 + 一句话说明。
  4. 未鉴权 GitHub API 60/hr：安全公告分页上限记为 ≥100，别假装有精确数。
  5. 本机装系统软件（Ollama/Docker）需 UAC：AI 在沙箱点不了，只产出脚本让用户本机跑。
