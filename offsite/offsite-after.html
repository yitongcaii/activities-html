Offsite · 知识库模块

好的 Offsite 实现

知识沉淀 · 成败TIPS · 角色分工 · 典型 Rundown

一句话定位：Offsite = 让少数人把难事想透并达成共识（向内收）；员工大会 = 把信息和大情绪传给很多人（对外扩）。本模块只讲前者，是 Offsite 实操标准与沉淀资产。

一、定义

基于部门组织 / 业务定位与当前机遇 & 卡点，在抽离日常的场域里，把问题摊开、对齐未来方向、产出具体解法。核心特征：小圈、深度、产出——不是团建旅游，不是小型员工大会。

二、标准环节（see → align → act）

三段式逻辑自洽：看见全貌 → 对齐方向 → 碰撞出行动。

环节作用关键做法
1. 业务图景共享打破信息孤岛（see）各单元讲「亮点+不足+对他人的需要」，现场画依赖/协同地图
2. 战略对齐把方向吵清楚（align）上层方向翻译到本团队，形成「战略落点清单」（坚持/砍掉/新做）
3. 研讨深度碰撞出具体行动（act）世界咖啡轮转，投票选 Top3 可落地动作并认领 owner

可选补充：开场建信任（破冰/共创愿景墙）；收口做承诺（承诺墙——每人写「回到岗位会做的一件具体小事」）。

三、目的与选型（一场只实现 1–2 个）

类别具体目的
对齐类战略对齐（融合/变革）、战略解码、新 leader 上任
解决类方向/业务/协作卡点、提高组织效率、挖掘潜在问题
探索类共谈发展机遇、发现业务/合作机会

四、成败TIPS

  1. 人要对：有决策权/话语权的人在场（通常 10–40 人）；融合期两边关键人都必须到
  2. 场要 open：开场立规则（保密/可 disagreement/发言机会均等）；姓名卡不写头衔；敏感场用专业引导
  3. 有前置（pre-work）：会前 1–2 周发 pre-read / 小问卷，把「机遇&卡点」先同步
  4. 有产出：研讨必须产出带 owner + 截止日的行动项
  5. 有跟进：散场 48h 内发纪要；90 天回溯行动/承诺兑现

五、角色分工

角色是谁负责什么
业务 Leader团队负责人内容 owner——定目标、定关键议题、当场拍板
HRBP（你）你场域设计 + 引导 + 跟进；退到幕后让对话发生
Facilitator内部有引导力者 / 外部带讨论、拉齐观点（敏感场建议外部）
PM / 统筹你或行政场地、物料、餐饮、行程
参与者核心团队真参与、出产出，不养旁观者

六、加分项

  • 共创：每个人都要参与发言 & 分享，不养旁观者
  • 行动：明确当下 & 未来的行为项，且真有人跟（对应 TIPS 4–5）

七、典型 Rundown

时间环节作用
09:00–09:30开场：定目的 + 立规则收心、立心理安全
09:30–10:30业务图景共享打破孤岛
10:30–12:00战略对齐共识落点
12:00–13:30午餐 + 轻活动（不强竞技）充电
13:30–15:00研讨（世界咖啡）出动作
15:00–15:15休息—
15:15–16:00总监 / 高管脱口秀（可选）松情绪
16:00–17:00协作挑战 / 主题跑步（可选）强关系
17:00–17:30承诺墙锁落地

重议题放上午；饭后安排轻互动；每 60–90 分钟休息。

八、常见翻车点（设计层）

  • 为 Offsite 而 Offsite：无清晰目的，变成"花了钱聊了天啥也没变"
  • HRBP 抢戏 / leader 念稿：没有真对话
  • 强制 fun：尴尬破冰、强竞技，成年人反感，关系更远
  • 只讨论不落地：出 10 条共识无 owner，三个月回原点
  • 人不对 / 场不 open：关键人没来，或敏感场没人敢说

九、附注：与员工大会的核心区别

员工大会Offsite
目的传达 / 表彰 / 声量对齐 / 融合 / 解决真问题
规模大（全员）小（核心圈 10–40）
形态一对多讲多对多共创
HRBP 角色执行统筹设计 + 引导
产出情绪 + 记忆行动项 + 共识
价值点当天散场后 90 天

组合打法：先 Offsite 让核心圈对齐方向 → 再员工大会向全员广播成果。
