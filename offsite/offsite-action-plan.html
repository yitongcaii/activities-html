〈团队/部门名称〉管理层 Offsite 落地作战手册

闭门战略对齐 + 信任建设 + 决策落地 · 2 天 1 晚 · 混合受众（②上下级 ↔ ③高管间）· 本手册=照着干的执行工具
形态：战略务虚 / 解码 / 复盘 筹备周期：T-90 立项 → T-1 物料 闭环：会后 48h 日志 → 30-60-90

00一页作战卡（先填这 7 项）

会前必须把下面 7 项填死，否则后面全在空转。主办方占位，不写死。

地点私密住宅式物业 / 目的地（山=战略 / 海=反思）；机场 90min 内；肩季 4-5/9-10 月省 10-25%
人数 / 名单≤16 人，只邀必要者；外部引导师 1 名（欧洲 €2.5–6k/天，最高 ROI 投入）
首要业务目标
财务语言		如「把 Top3 倡议决策延迟砍半」而非「团队凝聚力」。翻成财务语言：避免 X 人替换成本 = 年薪 50–200% × N
预算总额人均 €1400–2600 基准；Quarter Rule（住宿/差旅/餐饮/活动各 25%）或 OSEB（场地35/餐饮30/编程20/其他15）

⚠️ 三条红线（素材高频共识，触任一条即失败）：① CEO 不主持自己的 Offsite——CEO 主持时高管会自我审查，高 stake 议题必请外部引导师；② 沉默≠同意——领导层沉默通常=不同意，显式点名张力；③ 信息双安全——闭门禁录/加密/门禁/NDA，参会只邀必要者。

02两天执行议程（小时级 + 每节带法）

原则：70% 战略工作 + 30% 关系建设；单节 ≤90min；每节只做「发散」或「收敛」单一模式（混用是常见失败根因）；按能量排程（高风险决策锁上午、创意工坊放下午、社交留晚上、下午 3 点前尽量散场）。

Day 1 · 信任 → 数据对齐 → 务虚发散

时间模块主持人/引导师具体怎么做产出 / owner
09:00–10:30软开场 + 信任建设（工作风格地图 / 欣赏式探寻 4D）引导师带：每人说「我最好 / 最差的工作风格搭档」；顶部先示范脆弱感，破层级壁垒心理安全基线 / 引导师
10:45–12:15数据对齐（跨职能 SWOT / 战略地图现状）先共享事实底座再讨论，避免「我以为」；用 round-robin 保全员发声，不让话密者垄断共享事实 / 各职能负责人
14:00–17:00务虚发散：战争游戏 / 红蓝军对抗分组扮演竞对（「若你跳去竞对怎么打我们」）3 轮反应-反制；领导只问不拍板；允许吵架；142 页 fact book 上墙 + 红绿黄贴纸标共识/分歧/待数据极端场景清单 + 分歧上墙 / 引导师
19:00–非结构化社交晚餐连接 ≈ 议程重要；不做节目，留白让关系自然发生情感记忆 / 信任

Day 2 · 收敛决策 → 解码落地 → 承诺

时间模块主持人/引导师具体怎么做产出 / owner
09:00–11:30收敛：锁定 3–5 条核心决策每条当场绑定 1 owner + 1 deadline（不接受「就说明未就绪」）；用「射箭练习」去政治化：42 倡议贴 5 个战略目标靶，自然 cull 无关项决策清单 v1 / 各 owner
13:30–16:00解码落地：战略→解码→经分（RACI / 共享 OKR / 倒推问责）把③的方向翻译成②可认领的季度目标；负责人现场承诺（参考中通服：每任务谈资源/能力/协作三要素 + 衡量标准）行动画布 / 责任互锁
16:00–16:30结尾仪式：Commitment Circle / 致未来信每人说「带回去的一条」；建立 30 天强化起点承诺圈记录 / HRBP
带法关键提示：① 沉默≠同意——领导层沉默常=不同意，显式点名张力（「这里对 X 有明显分歧，摊开而非跳过」）；② 把人与立场分开，让各方讲驱动底层顾虑；③ 能量低谷（午后）用轻量激活/45+15 节奏顶住；④ 单日目标 <3 个深话题，留白即设计。

03核心环节执行 SOP（操作步骤 + 物料 + 翻车点）

③ exec商业战争游戏 War-gaming
物料：竞对 fact book（≥100 页上墙）、红/绿/黄 Post-it、白板、分组牌
  1. 分组：2–3 组，每组扮演一个竞对或内部红蓝军
  2. 给 3 轮「反应-反制」循环：A 出招 → B 反制 → A 再调
  3. 逼出最极端场景（极端态讨论清楚，中间态自然高质量）
  4. 红绿黄贴纸：绿=共识 / 黄=分歧待数据 / 红=高分歧高重要，优先聚焦红黄
翻车点：CEO 主导变「一言堂」→ 引导师控场，CEO 只提问；倡议过多 → 用「射箭练习」去政治化 cull；时间框架未对齐（「长期」对 A 是 10 年、对 B 是 10 季度）→ 先锁时间口径。
② sup行动学习工作坊（真课题共诊→共创→共担）
物料：真实业务课题卡、逻辑树/5Why/鱼骨图模板、收益-难度矩阵、城镇会议质询板
  1. 选 1 个真实痛点课题（非虚构练习）
  2. 共诊：逻辑树/5Why/鱼骨图挖根因，不甩锅
  3. 共创：收益-难度矩阵收敛方案
  4. 城镇会议：跨组质询，方案过关才认领
  5. 共担：训后小组不解散，持续复盘落地
翻车点：课题太虚 → 必须用真实业务；只讨论不落地 → 城镇会议强制认领 owner。
② supAAR 任务后复盘（收尾嵌入）
物料：四问卡片（打印，每人一份）
  1. 目标是什么？（当初要达成什么）
  2. 实际发生什么？（无责难，只谈绩效不评人）
  3. 哪里做得好？（固化）
  4. 下次哪不同？（捕获洞察级联）
翻车点：变「甩锅会」→ 顶部先示范脆弱感（「不为谁做错，为团队更锐」）；小但恒（15min huddle 也够）。
②+③战略解码会（衔接档：务虚→解码→经分）
物料：战略地图 / OGSM-T / PBC 责任互锁表
  1. 务虚定方向（③ 输出 3–5 条）
  2. 解码拆：每条拆部门任务，谈资源/能力/协作三要素 + 衡量标准
  3. 经分调：倒推问责，负责人现场承诺
翻车点：解码不互锁 → 用 PBC 把责任绑死；只定不跟 → 进 PM 系统 + 30-60-90。
