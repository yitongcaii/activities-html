飞书多维表格 · 薪资核查看板 配置方案

一张表承载「原始数据 → 自动校验 → 异常标红 → 仪表盘预警」，让每次核算从"重算一遍"变成"跑一遍看板"。

字段清单关键公式条件格式仪表盘自动化

一、整体架构

建议建 1 张主表 + 1 个仪表盘 + 2~3 个视图，不拆多表也能跑通核查：

  • 主表《薪资核算明细》：每行一个人·一个月，所有字段在此。
  • 仪表盘《薪资核查驾驶舱》：总额、部门分布、异常分布、趋势。
  • 视图：全部数据 / 异常清单（筛选异常）/ 按部门看板。
  • 高级权限：HRBP 可编辑、部门负责人只看本部门、财务看汇总不可改。

三、关键公式（粘贴即用）

① 应发工资

{基本工资}+{岗位工资}+{绩效工资}+{津贴补贴}+{奖金}+{加班费}-{缺勤扣款}

② 实发工资

{应发工资}-{社保个人}-{公积金个人}-{个税}-{其他扣款}

③ 环比波动%

IF({上月实发}>0,({实发工资}-{上月实发})/{上月实发},0)

④ 校验结果（核心，不平就标红）

IF(ABS({应发工资}-({基本工资}+{岗位工资}+{绩效工资}+{津贴补贴}+{奖金}+{加班费}-{缺勤扣款}))>0.01,"应发合计不平",IF(ABS({实发工资}-({应发工资}-{社保个人}-{公积金个人}-{个税}-{其他扣款}))>0.01,"实发不平","通过"))
💡 维度可再加：社保基数匹配 = IF(ABS({社保基数}-{应发工资})/{应发工资}>0.4,"基数疑似未更新","")，并入校验结果。

四、条件格式规则（逐条配置，命中即标色）

#规则触发条件效果
1漏发实发工资 = 0 或 为空红
2波动异常环比波动% > 0.2 或 < -0.2红
3漏税风险个税 = 0 且 应发工资 > 10000红
4校验失败校验结果 ≠ "通过"红
5离职多算入离职状态 = 离职 且 计薪天数 = 当月全月红
6基数滞后社保基数 < 应发工资 × 0.6黄
7银行卡缺失银行卡号 为空黄
8薪资倒挂（进阶）同部门同职级，本人实发 > 司龄更长者实发（需关联/分组公式）黄
⚠️ 倒挂核查较复杂，可先用手动筛选"同部门同职级按实发排序"肉眼看，公式版作为进阶。

五、仪表盘配置（核查驾驶舱）

数字卡

  • 本月发薪总人数
  • 薪资总包（应发合计）
  • 人均实发
  • 异常人数

柱状图

  • 各部门实发总额（叠加上月对比）
  • 异常类型分布（校验不平/波动/漏税/倒挂）

折线图

  • 近 6 月薪资总包趋势
  • 各部门环比波动

明细表

  • 异常清单：筛选 校验结果≠通过 或 标红行
  • 支持按部门/异常类型下钻

六、视图配置

  • 表格 全部数据：HR 核算主战场，含全部字段。
  • 表格 异常清单：筛选 校验结果≠"通过" 或 标红，仅看要处理的人。
  • 看板 按部门：分组=部门，每组看人数与总额，部门负责人只看自己组（配合高级权限）。
  • 仪表盘 核查驾驶舱：见上。

七、自动化（让机器跑流程）

  • 异常即时推送：当 校验结果 由"通过"变为异常 → 飞书消息通知 HRBP + 财务，带姓名与异常原因。
  • 核算启动提醒：每月 T-5 自动提醒"薪资数据已锁定，请启动核算"。
  • 异常汇总：标记异常的行自动同步到《异常记录表》，留痕可追溯。
  • 部门确认：T-2 自动给各部门负责人发"请确认本部门薪资"卡片。

八、落地节奏（不发错靠排期）

T-5
数据锁定：考勤/绩效/变动数据收集截止，导入主表。
T-3
第一轮核算 + 自查：跑公式与条件格式，异常清单全员过一遍。
T-2
部门确认：负责人确认本部门，自动化推送卡片。
T-1
HRBP + 财务复核：看仪表盘总额环比，签字放行。
T
发薪：导出实发，对接银行代发。
✅ 搭好后，每次核算 = 导入新月份数据 → 看板自动标红 → 处理异常 → 放行。重点从"重算"转为"查异常"。
