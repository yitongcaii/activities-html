1. 暖场

【cue: 候场轻音乐起】

主持人：

（微笑，等会场静下来）

先把手机调成静音吧——咱们今天要聊点大事，别让通知声把灵感打断了。

今天有点特别，除了 {现场城市} 现场，线上 {城市列表} 的伙伴也都在。来，镜头两边，把手举起来挥一挥！

平时大家都在业务一线连轴转，难得凑这么齐。今天不聊琐细，就聊一件事：{主题}。

（语气放轻，像说悄悄话）

我打个比方——{隐喻意象｜如：把今天当成一次"校准航海图"：平时各跑各的航线，今天把图摊开，看看大家是不是同一张}。

2. 热身 · 目标对齐

【cue: 问卷二维码投大屏】

主持人：

开场先不急着定调，先听听大家心里那杆秤。

大屏上有个问卷，每人填一个 flag——{flag 示例｜模板示范：今年你最想攻下的一个山头}。填完咱们抽签，抽到的伙伴聊两句。

（抽答示例｜模板示范：抽到一位说"最想让跨部门协作别再靠我个人刷脸"——全场点头，话题自然落到今天研讨的主线）

这问题太实了，咱们今天圆桌就专门聊它。

3. 主题研讨 · 分组圆桌

【cue: 分组就位，白板推上台】

主持人：

接下来进入正题。咱们分 {组数｜如：4} 个圆桌，每组认领一块：{议题方向｜如：增长 / 组织 / 能力 / 协同}。

每个组做两件事：一，写一句你们的 Slogan——不是喊口号，是你们这组对 {主题} 的最准一句话；二，给现在的信心打 1 到 10 的分。

（研讨巡场｜模板示范：巡场时听到一组 Slogan 是"把不确定性当素材"，挺好，等会儿咱们回扣）

时间到，请每组把 Slogan 和信心指数贴到白板。

我刚才转了一圈——{接话扣题｜如：分数最低的组，恰恰是对协同最较真的那组；痛点就在协同，这正是今天要破的局}。

4. 沉淀 · 便利贴 3-2-1

【cue: 便利贴与马克笔发到每桌】

主持人：

聊了半天，得落点东西。每人三张便利贴：3 个收获、2 个马上能做的动作、1 个开放问题，贴到墙上。

（念一张｜模板示范：收获——原来三个组都在抢同一类客户；你看，咱们不是各下各的，航线是连着的）

看墙后我念一张：{接话扣题｜如：三个收获最后都指向同一个词——对齐。这就是今天最值钱的东西}。

5. 总结 · 高管收束

【cue: 高管上台音乐】

主持人：

压轴的话，留给 {最高领导职位/姓名}。

其实每年到这时候，大家最想听的，不是 KPI，是那句"辛苦了"，还有——接下来这盘棋，到底怎么下。有请 {最高领导} 给咱们收个束，把今天的航线最后点一遍。

掌声有请！

6. 文化礼物 · 扇子写祝福

【cue: 定制扇子与马克笔分发】

主持人：

最后留个温度。每人领一把 {礼物名｜如：定制扇子}，写一句给团队、也给自己的一句话。不公开念，带回去留个念想。

（轻自嘲）我这主持也就是个串场的，干货都在各位手里。扇子上的话，比我说的一万字都管用。

结尾三件套

【cue: 合照提醒】

主持人：

光荣属于过去，接下来的路还得咱们自己走。

来，在这样的时刻，咱们留张全家福。靠得近的靠拢点——{合照提醒｜如：涉及敏感信息的同事往后站一步，拍张"不涉密"的合影}。

{主题口号｜如：校准航线，同向同行}，{年份} 咱们接着干！

【cue: 散场音乐】

今天到这儿，{散场指引｜如：晚宴在 X 层}。慢走。
