暖场

开场前 10 分钟 · 循环播

亲爱的各位〔家人 / 同事 / 伙伴 / 朋友〕，我们的【活动全称】将在十分钟后准时开始，请将手机调到静音或关闭，感谢支持与配合。

▶ 5 分钟 / 1 分钟 / 30 秒 重复同上；最后 30 秒：▶ 请全体随我一同倒数 10·9·…·1，迎接【活动全称】！

（多位领导：A→B→A 轮替，"感谢上一位 → 有请下一位"接龙，避免冷场）

B接下来有请【职务 姓名】为我们作【上年度】回顾与【本年度】展望，掌声有请！

（汇报后）感谢【姓名】精彩的讲述。进阶玩法：达成目标的负责人当场领奖，强化业绩导向。

5

颁奖环节

AB互抛，避免单调

B接下来的环节，是【公司名】【上年度】优秀表彰仪式，请看大屏幕！

▶ 播放表彰视频 → 颁奖嘉宾登台 → 获奖代表上台

A先说句心里话：这一年，我们和身边人待在一起的日子，可能比和家里人还多。台下这些面孔，是比家人还熟的战友——今天，该轮到他们被看见了。

B首先颁发【年度感动团队奖】。一张工位、一盏深夜的灯，你们把"不容易"熬成了"了不起"，有请获奖团队代表上台！

A让我们掌声有请【职务—姓名】为优秀团队颁奖！

合把最热烈的掌声，送给优秀团队，也送给颁奖嘉宾！

其余奖项照此循环：奖项名 + 2句画面感颁奖词（口语押韵都行，别写长篇抒情）+ 颁奖嘉宾，仅替换三项。上面 B 的颁奖词即范例，直接改文案。分 2–3 轮穿插在游戏 / 抽奖之间，避免连续颁奖冗长。

6

互动游戏

AB一搭一唱，制造反差笑点

A接下来到了大家最开心的互动游戏环节！

B听说今天的游戏，输的人要接受小惩罚哦，大家敢不敢上？

A【游戏名】规则：______（规则自行拟定，或沿用往届成熟玩法）。

B有没有自告奋勇的同事？来，把掌声送给我们的游戏勇士！

双人游戏控场：一人讲规则、一人调动气氛；用"没听到，再来一次"逼出欢呼；每轮控 5–8min。

抽奖环节

AB配合念名 + 造悬念

B亲爱的朋友们！终于到了大家盼望已久的抽奖环节！

A首先抽取的是【幸运奖 __ 名】，分 __ 次抽取，每次 __ 个！有请抽奖嘉宾【姓名】——

▶ 嘉宾抽奖 / 砸金蛋 / 摸球，B主持高声念名 + 礼仪引导上台

B中奖号码是：______ ！祝贺他们！没抽到的朋友别灰心，大奖还在后面。

A三等奖 / 二等奖 / 一等奖 / 特等奖 依次抽取。

B特别感谢【供应商名】对本次抽奖的赞助支持！

双人抽奖：一人报"接下来抽什么奖"，一人念号造悬念，配合更顺。

8

温情 / 视频环节

AB合诵，推情绪峰值

A说了这么多高光时刻，我想请大家把目光从舞台，挪到屏幕里。

B接下来这段视频，没有脚本，只有我们这一年真实的样子（播放《我们的故事》/ 海外同事拜年视频）。

▶ 播放视频，全场熄灯 / 聚光

A你可能在屏幕里看到了自己，也看到了那个总帮你兜底的人。

B此刻仍在地球另一端坚守的同事——把掌声，献给这些没能到场的【公司名】伙伴！

峰值情绪环节，放在颁奖与抽奖之间：激昂 → 温情 → 再推高潮。视频别太长（3–5min），配乐压低，主持不抢词。

领导祝酒 + 全员宣誓

可选，偏庄重

合【N】年来，梦想从未间断，热情从未退减，脚步从未停歇，斗志从未熄灭！

A下面，让我们用最热烈的掌声有请【总裁 / 董事长 姓名】登台，为我们开启胜利和荣耀的美酒！

▶ 举杯 / 全员起立

（祝酒后可选"全员宣誓"：起立、举右手握拳，念企业誓言，强化归属感）

谢幕 + 散场引导

收尾

A书翻到了这一页，但咱们的故事还没写完——下一章，留给明年的此刻。

A请各位有序离场、带好随身物品；

B未领奖的同事请至【领奖处】，意犹未尽的朋友可移步〔合影墙 / 茶歇区〕继续交流。

合【活动全称】——到·此·结·束！谢谢大家！
