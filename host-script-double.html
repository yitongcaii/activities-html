（多位领导：A→B→A 轮替，"感谢上一位→有请下一位"接龙）

A让我们再次用热烈的掌声对领导们的讲话表示感谢！

B让我们掌声有请【职务—姓名】为优秀团队颁奖！

（其余奖项：A/B交替念奖项名 + 引颁奖嘉宾，仅替换"奖项名 + 嘉宾"）

颁奖分 2–3 轮穿插在游戏 / 抽奖之间；AB交替念词，比单人更有层次。

AB一搭一唱，制造反差笑点

A接下来到了大家最开心的互动游戏环节！

B听说今天的游戏，输的人要接受"惩罚"哦，大家敢不敢上？

A【游戏名】规则：______（规则自行拟定，或沿用往届成熟玩法）。

B有没有自告奋勇的同事？来，把掌声送给我们的游戏勇士！

双人游戏控场：一人讲规则、一人调动气氛；用"没听到，再来一次"逼出欢呼。

A首先抽取的是【幸运奖 __ 名】，分 __ 次抽取，每次 __ 个！有请抽奖嘉宾【姓名】——

（嘉宾抽奖，B主持高声念名 + 礼仪引导上台）

B中奖号码是：______ ！祝贺他们！没抽到的朋友别灰心，大奖还在后面。

A三等奖 / 二等奖 / 一等奖 / 特等奖 依次抽取。

B供应商赞助奖项，我们要特别感谢【供应商名】的支持！

双人抽奖：一人报"接下来抽什么奖"，一人念号造悬念，配合更顺。

AB合诵，推情绪峰值

B今晚，让我们通过视频重温奋斗历程（播放《我们的故事》/ 海外拜年视频）。

此环节是"峰值体验"关键，放在颁奖与抽奖之间，情绪从激昂回落温情再推高潮。

双人配合要点

附录
  • 互抛接话：一人抛观点、一人接情绪，避免各念半句不搭。
  • AB反差：用性别 / 性格反差制造笑点（严肃A + 活泼B）。
  • 救场分工：一人卡壳，另一人立刻接"刚才说到……"圆回来，别双双愣住。
  • 站位与眼神：侧台互给手势（OK = 放音乐），别两人均摊抢话。
  • 合诵点题：关键句（开场 / 谢幕）合诵，比单人更有气势。
