一、怎么判断数据有没有错

逐条对照 · 拿源文件复核

1源对不对

报告里的数，是不是从你说的那份文件来的？agent 常偷偷读错 sheet 或拿旧文件。

例：博闻看板读的是 最新学员明细.xlsx，还是上个月那版？活动人数拉的是智能表格还是群接龙截图？

2算对没

抽 1 个数自己拿源文件手算：加总 / 去重 / 人均 / 占比，逐项核对。

例：人均参与深度 = 总人次 ÷ 去重人数，手算一次；简历"覆盖__人"对不对得上原始名单行数。

3口径守没守

你定的规则它有没有偷换？没写清口径的报告，默认当错。

例：博闻"<15min 剔除 + 空白排除"有没有真去掉；简历数字先用__占位、定稿标【待补】。

4有没有编

看有没有无中生有的案例 / 数字 / 引用——你从没给过却出现在报告里。

例：冒出一个你从没办过的活动名称、一个漂亮得可疑的达标率 100%。

二、30 秒快速验错 3 招

不用全查，先扫这三处
⚡
抽一个你心里有数的数
你知道某场来了 23 人，报告写 23 就对，写 32 就是算错或读错源。
⚠️
警惕"太整齐"的数字
全员达标率 100%、人均恰好 2.0，大概率是 agent 圆出来的，不是真算的。
📌
看口径说明在不在
正规报告会写"已剔除<15min"。没写就是没做，默认当错。

三、让 agent 自己复查的话术

直接丢给它 · 答不出来源即不可信
点复制 → 发给 agent 
这是你出的报告。请逐条说明：
① 每个核心数字来自哪个源文件哪一行；
② 计算口径（去重 / 剔除规则）是什么；
③ 标出 3 个你最没把握、建议我手算复核的数字。

👉 它如果答不出"来自哪一行"，这条数据就不可信。

四、怎么尽量让数据没错（前置防错）

做报告前就卡死 · 比事后查省 10 倍

1锁源

指定精确文件路径 + sheet，明令"不准自己找别的"。

例：博闻看板只许读 学员明细_2026Q2.xlsx 的"明细"sheet，别拿旧版或截图。

2写死口径

把你的规则逐条变白纸黑字，别让它"自己理解"。

例："<15min 且空白剔除；去重按工蜂 ID；人均 = 总人次 ÷ 去重人数"

3先确认再干

让它先用一句话复述口径，你点头再出数——逼它把误解暴露在前。

例：防止它把"去重人数"理解成"参与人次"。

4埋基准数

给 1 个你 100% 确定的数当试金石，让它先对上再信其他。

例："你知道 3 月那场来了 23 人，先对这个数"，对了再信其余。

5内嵌溯源

每个核心数字后标来源行 / 单元格，你一眼能复核。

例：报告写 "覆盖 312 人（源：明细!B2:B313 去重）"。

6占位防编

没给真实值的数用 __ 或【待补】，不许估算填写——正是你定稿口径逻辑。

例：简历数字、活动反馈份数一律留白，定稿时你亲自填。

五、可直接复制的防错指令模板

做报告前发它 · 填空即可
填空后复制 → 发 agent 
做之前先做到这 6 条：
① 只使用我指定的文件 __ 的 sheet __，不准用其他来源；
② 严格按口径：__（逐条写）；
③ 先用你自己的话复述一遍口径，等我确认再动手；
④ 报告里每个核心数字后标注来源行号；
⑤ 凡是我没给真实值的数字，用 __ 占位，不许估算填写；
⑥ 最后单独列一段"本次我做了哪些假设"，供我核对。
