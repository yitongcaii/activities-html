零次方机器人 · 招聘开展逻辑图

11 步招聘逻辑串联：前期准备 → 找人 → 落地

前期准备（摸底 · 搭台）
1

简历库盘点

梳理在库 / 在聊 / 待入职，避免重复挖、接住前任线索。

2

岗位画像

定职责 / 要求 / 汇报线。

3

职级薪酬宽带

建职级与薪酬区间，锁期权尺度。

4

招聘流程 SOP

定轮次 / 面试官 / 决策权 / 审批链。

5

面试题目准备

按画像设计题目，与 tech lead 共建。

→
找人
6

了解目标圈层

摸技术社区 / 实验室 / 竞品 / 开源。

7

人才地图

清华刘厚德组 / 竞品 / 顶会作者。

8

选择招聘渠道

校招 / 社招 / 内推 / 社交宣传。

9

雇主品牌

创始人故事 / 技术愿景素材。

→
落地（执行 · 机制）
10

面试 / 谈薪 / 入职 / 关怀

闭环执行，招得进也留得住。

11

数据看板

漏斗 + 渠道 ROI，用数据立信。

怎么看这张图：三列 = 招聘推进的三大环节（前期准备 → 找人 → 落地），列间箭头表示先后； 每列内纵向堆叠的节点 = 该环节内的步骤顺序（上→下执行）。 其中前期准备合并了原「摸底 + 搭台」，**落地**合并了原「执行 + 机制」。 数据看板（⑪）虽排在落地环节，实际应贯穿全流程持续跟踪。
