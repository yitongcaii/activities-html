暖场

开场前 10 分钟 · 循环播

亲爱的各位〔家人 / 同事们〕，我们的年会将在十分钟后准时开始，请将手机调到静音或关闭，感谢支持与配合。

（五分钟 / 一分钟 / 30 秒 同上，最后：）各位亲爱的〔家人 / 同事们〕，我们的年会将于 30 秒后开始——请随我一同倒数，迎接我们的【____】年会！

开场白

主持独自登台

尊敬的各位领导、各位来宾，亲爱的同事们、朋友们：大家【上午 / 下午 / 晚上】好！

我是本次年会的主持人【______】，非常荣幸站在这个舞台，和大家一起欢度这个开心、轻松、美好的时刻。

辞旧岁，迎新春，我们迎来了【公司名】【____】年会。今天，我们欢聚一堂，共庆昨日辉煌，展望美好未来！

风雨兼程，我们共同走过；踏平坎坷，我们创造了卓越的成绩；我们难以忘怀：希望、收获与成长。

有全体同事的辛勤付出，才有公司今天的成就——在此向全体同事致以最崇高的敬意：你们辛苦了，你们是最可爱的人！

下面，让我们用最热烈的掌声有请【职务—姓名】为本次年会致辞！

领导致辞

单人接龙的写法

（领导讲话毕）

感谢【姓名】总精彩的致辞。【上年度】是值得【公司名】人回味的一年——有鲜花、有掌声，有汗水、有泪水，有风和日丽、也有惊涛骇浪。

接下来，让我们掌声有请【职务—姓名】上台致辞！

（多位领导依次：每讲完一位，用"感谢【上一位】→ 有请【下一位】"接龙，避免冷场）

让我们再次用热烈的掌声，对各位领导的讲话表示感谢！

工作回顾 / 战略展望

可选

回顾【上年度】，千言万语汇成一个词——【感动 / 感恩 / 突破】。

接下来有请【市场 / 运营总监 姓名】为我们作【上年度】工作回顾及【本年度】工作展望，掌声有请！

（汇报后）感谢【姓名】总精彩的讲述，令人鼓舞、催人奋进。

进阶玩法：设"对赌奖金发放"——达成目标的负责人当场领奖，强化业绩导向。

颁奖环节

团队奖 / 个人奖都用同一套句式

接下来的环节是【公司名】【上年度】优秀表彰仪式，请看大屏幕！

（播放表彰视频 → 邀请颁奖嘉宾登台 → 获奖代表上台）

首先颁发的是【上年度—年度感动团队奖】，请获奖团队代表上台领奖。

让我们掌声有请【职务—姓名】为优秀团队颁奖！

让我们用热烈的掌声，感谢以上优秀团队做出的卓越贡献，也感谢我们的颁奖嘉宾！

（其余奖项照此循环，仅替换"奖项名 + 颁奖嘉宾"）

颁奖分 2–3 轮穿插在游戏 / 抽奖之间，避免连续颁奖冗长。

互动游戏

单人讲解规则 + 组织，靠观众欢呼控场

接下来到了大家最开心的互动游戏环节！

【游戏名】规则：______（规则自行拟定，或沿用往届成熟玩法）。

有没有自告奋勇的同事？来，把掌声和欢呼声送给我们的游戏勇士！

单人场游戏要"短平快"，每轮控制 5–8 分钟，用"没听到，再来一次"调动气氛。

首先抽取的是【幸运奖 __ 名】，分 __ 次抽取，每次 __ 个！有请抽奖嘉宾【姓名】——

（嘉宾按动系统 / 砸金蛋 / 摸球，主持高声念名 + 礼仪引导上台）

中奖号码是：______ ！祝贺他们，请到领奖处领取奖品。

三等奖 / 二等奖 / 一等奖 / 特等奖 依次抽取。供应商赞助奖项：主持需点名感谢供应商。

温情 / 视频环节

制造峰值感动

时光飞逝，【公司名】见证了我们的成长，我们也见证了【公司名】的发展！

今晚，让我们通过视频重温奋斗历程（播放《我们的故事》/ 海外拜年视频）。

在地球另一边的海外同事仍坚守岗位——让我们把掌声献给这些【公司名】勇士！

此环节是"峰值体验"关键，放在颁奖与抽奖之间。

领导祝酒 + 全员宣誓

可选，偏庄重

【N】年来，梦想从未间断，热情从未退减，脚步从未停歇，斗志从未熄灭！

下面，让我们用最热烈的掌声有请【总裁 / 董事长 姓名】登台，为我们开启胜利和荣耀的美酒！

（祝酒后可选"全员宣誓"：起立、举右手握拳，念企业誓言，强化归属感）

【活动全称】——到·此·结·束！谢谢大家！〔备选收尾合唱：《相亲相爱一家人》/《同一首歌》〕

单人控场心法

附录
  • 自问自答补空白：没人接话时，自己抛"刚才这轮游戏，最拼的是谁？——我投【X】一票"，制造节奏。
  • 点名互动救冷场：提前备 2–3 个"内定"同事名字，冷场立刻点，不干等。
  • 音乐 / 视频补位：单人撑不住时切一首歌 / 一段视频，自己退到侧台喘口气。
  • 语速与停顿：单人最忌连珠炮，关键句后留 2 秒掌声空隙。
  • 与音控暗号：定一个手势（比 OK = 放音乐，握拳 = 切麦），减少对着空气喊。
